## 2.2 三层 Pipeline 抽象（v5 重构核心）

```
agent_run_runtime.py (统一 SSE 入口)        ← 不替换，加 auth 中间件
   ├── pipeline_runtime.py                  ← 替换为 LangGraph（试点 query_attribute）
   │   场景: smart_qa / smart_metric / smart_conn / smart_traceability
   │
   └── scheduler_core.py                    ← 不替换（DAG 即时执行已够）
       场景: query_entity / query_attribute（保留 legacy 路径 + LangGraph 路径并行）
```

> 现状（2026-06）：仅 `query_attribute` 完成了 LangGraph 化试点；其他能力仍走 `SchedulerCore` + `pipeline_runtime.PipelineRuntimeService`。

## 2.3 关键数据流：一次"问属性"请求

```
1. 前端 SmartQA / QueryAttribute 页面
   → POST /api/v1/query-attribute/example-metadata 或 /map
2. FastAPI router (query_attribute.py)
   → 鉴权（auth_middleware → request.state.user）
   → 路由到 query_attribute_service.query_attribute_map()
3. query_attribute_service (services/query_attribute_service.py)
   → 读 kg_smart_planner_configs 决策
   → 调 query_attribute_skill_runtime（特性开关）
       ├─ QUERY_ATTRIBUTE_USE_LANGGRAPH=0  → 走 SchedulerCore
       │   → SchedulerCore.execute_workflow(workflow_code=query_attribute_main_workflow)
       │       → 按 step 顺序逐个执行龙虾技能（ExecutionEngineV2.execute_by_code）
       │       → 每步落库 kg_smart_pipeline_step_runs
       │       → SSE emit step.started/step.completed
       └─ QUERY_ATTRIBUTE_USE_LANGGRAPH=1  → 走 LangGraph
           → query_attribute_langgraph.run_query_attribute_via_langgraph()
           → StateGraph 6 步 + InMemorySaver
           → SkillNodeFactory 包装每步为 LangGraph node
               → 内部仍调 ExecutionEngineV2.execute_by_code()
               → 同样落库 + emit
4. SSE 事件流推回前端
   → ConversationMessageList / WorkflowExecutionTimeline 渲染
5. 前端 UserBadge 验证 is_anonymous / roles（Authentik 或 anonymous）
```

## 2.5 关键不变量（必须守住的对外契约）

> 来源：[`docs/REFACTOR_DESIGN_v5_20260612.md`](../docs/REFACTOR_DESIGN_v5_20260612.md) §0.2

| 契约 | 说明 |
|------|------|
| **SSE 11 事件协议** | `run.started / context.prepared / step.started/completed/failed / assistant.delta / tool.delta / block.completed / message.card / run.completed/failed / stream.end` |
| **skill_api_bindings.target_ref 机制** | `target_ref="service:foo_service.method"` 字符串解析为 `getattr` 调用 |
| **PythonExecutor 6 全局沙箱注入** | `_db_session / _common_stop_words / _standard_dict / _nl2cypher_semantic_data` + 新增 `_current_user / _retriever` |
| **资产矩阵打点 API 方向不对称** | URL `entity_id=L4X / target_entity_id=L2X`，写库时 `source=L2X / target=L4X` |
| **kg_smart_pipeline_runs / step_runs / rewind_logs 表 schema** | 沿用，LangGraph Checkpointer 写入这些表（审计追溯不依赖 InMemorySaver） |
| **kg_dag_workflows / executions / step_executions 表** | scheduler_core 不动 |
| **MySQL 100% 持久化主源** | 业务真源永远在 MySQL，Neo4j/Qdrant 是检索副本 |

## 2.6 三种"问"的横向对比

| 维度 | QueryEntity | QueryAttribute | SmartMetric |
|------|-------------|----------------|-------------|
| 入口 | `/api/v1/query-entity/...` | `/api/v1/query-attribute/...` | `/api/v1/smart-metric/...` |
| 输入 | 自然语言问"实体集合" | 自然语言问"实体+属性" | 自然语言问"指标" |
| 主要场景 | 找"用电户"列表 | 找"用电户.客户名称、行业分类" | 找"客户数"+"按行业分组" |
| 编排 | SchedulerCore 5 步 | SchedulerCore 6 步 **+** LangGraph 6 步（试点） | SchedulerCore N 步 |
| 落库 | kg_smart_pipeline_* | kg_smart_pipeline_* | kg_smart_pipeline_* + kg_metric_query_logs |
| 关键文件 | `query_entity_service.py` | `query_attribute_service.py` + `query_attribute_langgraph.py` | `smart_metric_steps.py` + `metric_center` |

## 2.7 安全架构

```
                   Authentik 2025.10  (OIDC issuer)
                            ▲
                            │ /authorize, /token, /jwks, /userinfo
                            │
┌──────────────┐    ┌───────┴────────┐    ┌──────────────────┐
│   Browser    │◀──▶│  FastAPI :8100 │───▶│ MySQL (auth_*)   │
│  (PKCE)      │    │ auth_middleware│    │ auth_users       │
│  localStorage│    │  _verify_jwt   │    │ auth_roles       │
└──────────────┘    │  _upsert_user  │    │ auth_user_roles  │
                    │ check_permission    │ auth_resource_acl│
                    └────────────────┘    └──────────────────┘
                            │
                            ▼
                    check_permission 优先级：
                      1. admin 角色 → 一票通过
                      2. _DEFAULT_ROLE_PERMS 角色默认权限
                      3. ResourceACL(principal=user, resource_id)
                      4. ResourceACL(principal=role, resource_id)
                      5. ResourceACL(principal=role, resource_id='*')
```

详情参见 [`05-认证与权限系统.md`](./05-认证与权限系统.md)。
