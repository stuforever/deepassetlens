# 03 · 后端模块详解

> 入口文件：[`backend/app/main.py`](../backend/app/main.py)
> 全部业务代码位于 `backend/app/`，下文按 `core / api / services / models / schemas` 五个子包组织说明。

## 3.1 应用入口 main.py

[`backend/app/main.py`](../backend/app/main.py) 是 FastAPI 应用入口，主要职责：

1. **lifespan 管理**（启动/关闭钩子）
   - `Base.metadata.create_all(engine)` — 自动建表
   - `ensure_schema_compatibility()` — 轻量级补齐新增列（参见 [04-数据模型与数据库](./04-数据模型与数据库.md)）
   - `init_db(db)` — 初始化概念/实体/SkillType
   - `VersionService.normalize_all_versions_to_filesystem(db)` — 同步技能版本到磁盘
   - `ensure_query_entity_workflow(db)` / `ensure_query_attribute_workflow(db)` — 引导默认工作流
   - `task_worker_manager.start(poll_interval=2.0)` — 启动后台任务消费线程
2. **中间件注册**
   - `CORSMiddleware(allow_origins=["*"])` — 开发态跨域放行
   - `BaseHTTPMiddleware(dispatch=auth_middleware)` — 全局 OIDC 鉴权
3. **路由注册**：21 个 v1 router + 1 个 v2 router，全部挂在 `/api/v1` 或 `/api/v2` 前缀
