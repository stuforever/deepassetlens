## 8.2 图谱建模（四级概念 + 资产矩阵）

### 8.2.1 概念层级

```
L0  (根) - 电カ图谱体系
├── L1 (根分类)
│   ├── 客户 (area_index=1)
│   ├── 设备 (area_index=2)
│   └── 供应商 (area_index=3)
│
│   ├── L2 (二级)
│   │   ├── 用电客户 (客户下)
│   │   ├── 发电客户 (客户下)
│   │   ├── 计量点 (设备下)
│   │   └── 电能表 (设备下)
│   │
│   │   ├── L3 (三级)
│   │   │   ├── 业扩接入&电源并网 (用电客户下)
│   │   │   └── 计量采集 (用电客户下)
│   │   │
│   │   │   └── L4 (四级)
│   │   │       ├── 业扩申请 (业扩接入&电源并网下)
│   │   │       ├── 电量采集 (计量采集下)
│   │   │       └── 功率采集 (计量采集下)
```

### 8.2.2 关键模型

```python
# models/base.py
class Concept(Base):
    __tablename__ = "kg_concepts"
    id        = Column(String(36), PK)
    name      = Column(String(255), nullable=False)
    level     = Column(Integer, nullable=False)         # 1/2/3/4

    system_names = Column(JSON)                          # 关联系统列表
    description = Column(Text)

class Entity(Base):
    __tablename__ = "kg_entities"
    id = Column(String(36), PK)
    concept_id = Column(String(36), FK("kg_concepts.id"), nullable=False)
    entity_code = Column(String(100), unique, nullable=False)
    entity_name = Column(String(255), nullable=False)
    entity_en_name = Column(String(255))
    entity_explanation = Column(Text)

    description = Column(Text)
    is_main_table = Column(Boolean, default=False)
    data_layer = Column(String(100))                     # ODS/DWD/DWS/ADS
    sort_order = Column(Integer, default=0)

class EntityRelation(Base):
    __tablename__ = "kg_entity_relations"

    relation_name = Column(String(255))

    direction = Column(String(20), default="forward")
    cardinality = Column(String(20), default="N:N")
    source_field_name / target_field_name
    join_expr = Column(Text)
    description / remark

class EntityConceptLink(Base):
    """中间表（v5 新）：Entity-Concept N:N"""
```
