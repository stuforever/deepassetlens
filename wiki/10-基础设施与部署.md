## 10.1 基础设施栈（6 容器）

`docker-compose.infra.yml` 启动下列服务（`--env-file .env.infra`）：

| 服务 | 镜像 | 内部端口 | 外部端口 | 用途 |
|------|------|----------|----------|------|
| `authentik-pg` | postgres:16-alpine | 5432 | - | Authentik 后端 PG |
| `authentik-redis` | redis:7-alpine | 6379 | - | Authentik 缓存/队列 |
| `authentik` | ghcr.io/goauthentik/server:2025.10 | 9000/9443 | **9100/9143** | OIDC issuer（实际用 9100） |
| `authentik-worker` | 同上 (worker 模式) | - | - | 后台任务 |
| `neo4j` | neo4j:5.24-community | 7474/7687 | **7474/7687** | 业务图副本（按需） |
| `qdrant` | qdrant/qdrant:v1.12.x | 6333/6334 | **6333/6334** | 向量库（按需） |

> ⚠️ `docker-compose.yml`（不带 .infra 后缀）当前为占位：仅保留 `volumes:` 段，注释说明 "postgres + neo4j 已移除：tupu backend 100% 走本地 MySQL 3306"。

### 10.1.1 一键启动

```powershell
cd d:\gitcangku\DB-GPT\tupu
docker compose --env-file .env.infra -f docker-compose.infra.yml up -d
```

健康检查：
```powershell
docker compose -f docker-compose.infra.yml ps --format "table {{.Name}}\t{{.Status}}"
# 期望：6 个容器 (Up X minutes (healthy))
```

## 10.5 Authentik 引导

`backend/authentik_bootstrap.json` 存了引导产物（含 OIDC Provider、Application、Scope Mappings 的 ID）。第一次启动会通过 `tmp_authentik_bootstrap.py` 调 Authentik API 写入。

关键步骤（来自 `OPERATION_MANUAL.md` §2.3）：

1. 浏览器访问 http://localhost:9100/ 用 `akadmin` 登录
2. **Directory → Users → Create** 建测试用户（如 `alice`）+ Set password
3. **Directory → Groups** 把 alice 加入 `tupu-admin` / `tupu-operator` / `tupu-viewer`
4. （关键）Provider 配置 Scopes，确保 `preferred_username` 和 `groups` claim 被注入 access_token — 详见 `OPERATION_MANUAL.md` §2.4

   ```json

       "user_query": "查用电客户的客户名称、行业分类、重要性等级",
       "metadata_source": "system",
       "metadata": {},
       "llm_connection_id": null
     },
     "step_results": {},
     "step_trace": [],
     "last_step_id": null,
   ```

5. 点 **Run** 看 6 步逐步执行
6. 中间任意步可点 **Edit** 改 state，再 **Resume** 续跑

## 10.10 重启清单（每次开机后）

```powershell
# 1. 基础设施
cd d:\gitcangku\DB-GPT\tupu
docker compose --env-file .env.infra -f docker-compose.infra.yml up -d

# 2. backend
cd backend
$env:PYTHONUTF8="1"
$env:ENABLE_AUTH="1"        # 想测权限就设 1，否则 0
python -m uvicorn app.main:app --host 127.0.0.1 --port 8100 --reload

# 3. frontend（新开窗口）
cd ..\frontend
$env:BROWSER="none"
npm start

# 4. （可选）LangGraph Studio（新开窗口）
cd ..\backend
$env:PYTHONUTF8="1"
$env:LANGSMITH_API_KEY="lsv2_pt_dummy"
langgraph dev --host 127.0.0.1 --port 2024 --no-browser --allow-blocking
```
