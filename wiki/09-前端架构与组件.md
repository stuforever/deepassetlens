## 9.3 关键组件

### 9.3.1 UserBadge（用户徽标）

[`frontend/src/components/UserBadge.tsx`](../frontend/src/components/UserBadge.tsx)
- 调 `GET /api/v1/auth/me` 拿当前用户
- 显示 username + roles + is_anonymous 标记
- ENABLE_AUTH=0 时显示 "anonymous" + "admin" + "权限关闭"

### 9.3.2 AuthGate（OIDC 守卫）

[`frontend/src/auth/AuthGate.tsx`](../frontend/src/auth/AuthGate.tsx)
- 未登录 → 跳 Authentik `/authorize`（PKCE）
- 已登录 → 渲染 children

## 9.5 HTTP 客户端

`package.json` 声明 `axios: ^1.6.2`，约定通过 interceptor 自动塞 Bearer：
```typescript
axios.interceptors.request.use((config) => {
  const t = getStoredToken();
  if (t) config.headers.Authorization = `Bearer ${t.access_token}`;
  return config;
});
axios.interceptors.response.use(null, (err) => {
  if (err.response?.status === 401) {
    clearToken();
    window.location.href = '/auth/login';
  }
  return Promise.reject(err);
});
```

## 9.7 SSE 流处理

`useConversationRun` hook 负责：
- 打开 EventSource（或 fetch + ReadableStream）
- 解析 SSE 11 事件
- push 到 useState（消息流）

```typescript
// useConversationRun.ts 概念示意
const useConversationRun = (scene, page) => {
  const [messages, setMessages] = useState<Message[]>([]);
  const run = async (input) => {
    const resp = await fetch(`/api/v1/${scene}/...`, { method: 'POST', body: JSON.stringify(input) });
    const reader = resp.body.getReader();
    const decoder = new TextDecoder();
    while (true) {
      const { done, value } = await reader.read();
      if (done) break;
      const chunk = decoder.decode(value);
      // 解析 "event: xxx\ndata: {...}\n\n"
      // 触发 setMessages(...)
    }
  };
  return { messages, run };
};
```
