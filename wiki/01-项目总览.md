# 01 · 项目总览

> 适用版本：2026-06-13 v5 重构后

## 1.1 项目定位

`tupu`（土普）是一套面向**电力行业**的"数据智能分析组件"平台，提供：

1. **图谱知识管理**：四级（L0-L4）概念-实体-关系-字段建模 + L2X/L4X 资产矩阵
2. **智能问数（NL2SQL/NL2Cypher）**：基于 LangGraph 的多步推理，支持问实体/问属性/问指标
3. **技能与工作流引擎**：5 类技能（自然语言/Python/SQL/HTTP/混合）+ DAG 工作流调度
4. **指标中心**：原子指标 / 衍生指标 / 维度绑定 / 业务口径全生命周期
5. **OIDC + RBAC + 资源级 ACL**：Authentik 单点登录 + 后端细粒度权限
6. **可视化编排**：基于 G6 的图谱/工作流编辑器、基于 Monaco 的技能编辑器

## 1.4 端口与服务总览

| 服务 | 端口 | 协议 | 启动方 |
|------|------|------|--------|
| frontend (React) | 3000 | HTTP | `npm start`（frontend 目录） |
| backend (FastAPI) | 8000 / 8100 | HTTP | `uvicorn app.main:app` |
| Authentik UI | 9100 | HTTP | `docker-compose.infra.yml` |
| Authentik HTTPS | 9143 | HTTPS | 同上 |
| Qdrant REST / gRPC | 6333 / 6334 | HTTP / gRPC | 同上 |
| Neo4j HTTP / Bolt | 7474 / 7687 | HTTP / Bolt | 同上 |
| LangGraph Studio dev | 2024 | HTTP | `langgraph dev` |
| MySQL（业务库） | 3306 | TCP | 用户自管 |

**8000 vs 8100 说明**：
- 8000 = 历史 backend 端口（不带权限集成）
- 8100 = v5 加入 Authentik 权限集成后默认端口
- 验证期两端口共存，确认稳定后可统一回 8000

## 1.5 五件套技能（Skill Filesystem Layout）

每个技能（Skill）以目录形式存储在 `backend/data/skills/<skill_code>/`：

```
<skill_code>/
├── SKILL.md                 # 技能说明（Markdown 格式，结构化解析）
├── requirements.txt         # 第三方依赖声明（pip / apt / env）
├── assets/
│   ├── input_schema.json    # 输入 JSON Schema
│   └── output_schema.json   # 输出 JSON Schema
└── scripts/
    └── main.<ext>           # 入口脚本（ext 按 skill_type 切换：py/sql/txt/yaml）
```

五种 `skill_type`：

| type_code | name | ext | 编辑器 | 入口格式 |
|-----------|------|-----|--------|----------|
| `natural` | 自然语言 | txt | PromptEditor | prompt 文本 |
| `python` | Python | py | PythonEditorV2 | `def main(input: dict) -> dict` |
| `sql` | SQL | sql | SQLEditorV2 | 单条 SQL |
| `http` | HTTP | yaml | HTTPEditorV2 | method/url/headers/body_template |
| `mixed` | 混合 | yaml | MixedEditorV2 | 多 step 序列 |

## 1.6 核心数据规模

- **业务真源**：MySQL `tupu` 库（3306），约 70+ 张业务表 + 8 张权限表
- **技能包**：~30+ 预置技能（涵盖 `query_entity_*`、`query_attribute_*`、`smart_qa_*`、`step*_*`）
- **运行执行**：单进程 FastAPI + 单线程 TaskWorker（polling 2s）
