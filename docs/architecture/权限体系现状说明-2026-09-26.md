## 1. 总原则

- 平台鉴权 = `backend/app/core/auth.py` 五层判定：`ENABLE_AUTH` 开关 → 公共路径放行 → OPTIONS 放行 → JWT 验签（auth=1）→ 匿名直通（auth=0）。
- **ENABLE_AUTH=false（开发态语义）= 匿名即 admin 直通**，是长期开发态约定（2026-09-24 用户定调），测试基建零依赖登录。
- 供应商（vendor sishu）自有身份面已**物理删除**（T6批3，ad06416）：vendor JWT/dt_token/users.json/PocketBase 分支全部不存在；换线桥= `backend/app/services/sishu_full/api/vendor_bridge.py`。

## 2. 身份层（登录签发）

- **SuperTokens 单容器**（tupu_supertokens，宿主 13567→容器 3567，数据落 tupu_pg/supertokens 库）——唯一身份提供方。
- **Authentik 已退役**（T7，0d40d3b）：容器停用；`AUTHENTIK_*` 环境变量为死配置（代码保留表驱动双跑痕迹 `core/auth.py:70-89`，运行时 AUTH_PROVIDER=supertokens，来源 `.env.infra:34`）。
- 验签：SUPERTOKENS_JWKS（`http://127.0.0.1:13567/.well-known/jwks.json`，Core 9.x 公开路径）；ST access token 不校验 iss/aud，验签+exp 即可。
- 前端登录页 `/login`（自研，StLogin chunk）；前端鉴权源=平台 `/api/v1/auth/me`（`useAuthStatus.ts`）。

## 4. vendor→平台换线桥（vendor_bridge.py）

- `platform_require_auth` = require_expert("use","sishu")；`platform_require_admin` = require_permission("sishu","manage")；`ws_require_auth`（?token= 平台 JWT，4001 关闭）；`require_auth(request=)` 手工解析（keyword 调用）。
- 教学工具身份跨 MCP 边界：X-Tupu-User + HMAC 签名（±300s，`mcp_server.user_sig_header`），装配时 `_build_agent` 注入、`/mcp` 面 `UserContextASGIMiddleware` 验签重建 ContextVar，缺头 fail-closed。
- auth=0 时 vendor 桥与 core/auth 双侧注入 anonymous/local-admin（用户名 `LOCAL_ADMIN_USERNAME`）。

## 5. 工具门控（三分类 + 两段臂）

- 单点：`backend/app/services/permission_vocab.py`。**TOOL_REGISTRY=40** = mcp_server 实际注册集（漂移由 `tests/test_iam.py` 用 `mcp.list_tools()` 实测断言把关）。
- **READONLY_TOOLS=26**：角色默认 `tool:["execute"]` 覆盖，允许/拒绝二态。
- **EXEC_TOOLS=14**：仅 ACL 显式授予（admin 一票通过；种子=`tool_gate.seed_tool_permissions` 幂等，viewer 除外）。执行走 **EXEC 两段臂**（`tool_confirm.py`：HMAC_SHA256 绑定 tool|args|user|ts ±300s；预检臂①签发 pending_confirmation、执行臂②携 token 执行；双审计 approval/allow/deny）。
- **签名一致性契约**：`tests/test_mcp_exec_signatures.py` 钉死"EXEC 件 schema 必含 confirm_token、READONLY 必不含"（T8a 曾出 execute_entity_api/execute_doris_sql 缺形参的潜伏 NameError，2026-09-26 复评时同一类缺陷在 execute_sql 再现并已补齐——此测试防复发）。
- **WRITE_TOOLS=6**（task/write_file/edit_file/execute/grep/glob）：系统级面外恒拒，= 引擎 ABSOLUTE_FORBIDDEN 同集，关系由测试钉住。
- 用户维度过滤（T5）：装配点 `filter_tools_for_user`（专家白名单 ∩ 用户/角色 ACL），fail-closed；auth=0/匿名 admin 全量。

## 6. 角色与资源 ACL

- 角色权威 = `auth_user_roles` 表（GROUP_ROLE_MAP 已退役）；系统角色 admin/operator/viewer（`_DEFAULT_ROLE_PERMS`）。
- 资源型 ACL：11 资源类型 × 动作词（`PERMISSION_VOCAB`，GET /api/v1/iam/vocab 原样吐出）；管理面 = 设置中心 iam 三页（users/roles/audit）。
- 专家赋权：`/expert-grants` 管理面 + `expert_auth.filter_visible_experts`（门户可见性执法点①）。
- 审计：`auth_audit_log` 表（decision 三值 CheckConstraint allow/deny/approval），门控两端点落账。
