## 1. Token 层扩展（`src/theme/tokens.ts`，只增不改）

在文件末尾新增四个导出块，并在 `tokens` 聚合导出里挂上：

```ts
/* ---------- 阴影层级（新增，S0-S3） ---------- */
export const elevation = {
  s0: 'none',
  s1: '0 1px 2px rgba(15,23,42,.04), 0 1px 3px rgba(15,23,42,.06)',
  s2: '0 4px 12px rgba(15,23,42,.08), 0 2px 4px rgba(15,23,42,.04)',
  s3: '0 12px 32px rgba(15,23,42,.14), 0 4px 8px rgba(15,23,42,.06)',
} as const;

/* ---------- 品牌渐变（新增，克制：仅落地页主视觉 / AI 徽标 / 主发送按钮 3 处） ---------- */
export const brandGradient = 'linear-gradient(135deg, #2563EB 0%, #7C3AED 100%)';

/* ---------- 图表色板（新增，画布/图谱循环取色，禁止随机色） ---------- */
export const chartPalette = [
  '#2563EB', '#7C3AED', '#0891B2', '#059669',
  '#D97706', '#DC2626', '#64748B', '#BE185D',
] as const;

/* ---------- 字号（新增 display，仅落地页主视觉用） ---------- */
// fontSize 对象内追加：
//   display: 28,

/* ---------- 动效 token（新增） ---------- */
export const motion = {
  duration: { fast: 120, base: 200, slow: 320 },
  easing: { enter: 'cubic-bezier(.2,.8,.2,1)', exit: 'cubic-bezier(.4,0,.6,1)' },
} as const;
```

`tokens` 聚合导出追加：`elevation, brandGradient, chartPalette, motion`。

**antd token 挂接（阴影让 antd 组件免费获得层级）：**

```ts
// antdThemeToken 内追加
boxShadow: elevation.s1,          // 普通容器
boxShadowSecondary: elevation.s2, // Popover/悬浮
// antdComponents 内追加
Modal: { boxShadow: elevation.s3 },
```

**antd Menu 圆角（左导航 hover 浮起的第一步）：**

```ts
// antdComponents.Menu
itemBorderRadius: 0,   // 改 =>
itemBorderRadius: radius.default, // 6
```

> 说明：Menu 现有 `itemMarginInline: 0` 保持不动，hover 时内边距由 index.css 作用域规则补（见 §4）。

## 4. 左导航浮起 + 会话操作图标 hover 显现（`AppSider.tsx`）

### 4.1 导航菜单 hover 圆角浮起（行 162-176）

- Sider 内层 div 加 `className="dal-sider"`（行 160 的 flex 容器）。
- antdComponents.Menu `itemBorderRadius` 已改 6（§1）。
- index.css 追加作用域规则（覆盖 antd 默认 hover）：

```css
.dal-sider .ant-menu-item { margin-inline: 4px !important; }
.dal-sider .ant-menu-item:hover { background: var(--bg-hover) !important; }
.dal-sider .ant-menu-item-selected { background: var(--color-primary-bg) !important; }
.dal-sider .ant-menu-item-selected:hover { background: var(--color-primary-bg) !important; }
```

> 说明：选中态保留 primaryBg+主色文字（设计不要求变）；hover 浮起 = 圆角 6 + bgHover，不加阴影（避免菜单项视觉噪音、保持性能红线）。

### 4.2 会话行操作图标 hover 才现（行 191-244）

- 会话行 div（行 192-206）加 `className="dal-session-row"`。
- 操作图标外层（行 226-243 的 `<>`）包一层 `className="dal-session-actions"`。
- index.css 追加：

```css
.dal-session-actions { opacity: 0; transition: opacity var(--motion-duration-fast) var(--motion-easing-enter); }
.dal-session-row:hover .dal-session-actions { opacity: 1; }
```

> 效果：编辑/删除 10px 图标默认隐藏，行 hover 时以 120ms 淡入；鼠标离开淡出。图标字号/颜色不变。

## 5. 页签 Chrome 化（`AppTabs.tsx:80-108`）

### 5.1 标签栏（行 63-75）

```tsx
// 背景 bgContent => bgPage（让激活页签"白底连接内容区"有对比）
background: tokens.colors.bgPage,
// 其余（height 36 / padding / borderBottom / gap）不动
```

### 5.2 页签项（行 80-108）

```tsx
style={{
  // 原 active: primaryBg => Chrome 形态：白底 + 主色顶边 + 仅顶部圆角
  background: isActive ? tokens.colors.bgContent : 'transparent',
  color: isActive ? tokens.colors.primary : tokens.colors.textTertiary,
  fontWeight: isActive ? tokens.fontWeight.semibold : tokens.fontWeight.regular,
  borderTop: isActive ? `2px solid ${tokens.colors.primary}` : '2px solid transparent',
  borderRadius: isActive ? '6px 6px 0 0' : tokens.radius.default,
  height: 30,                       // 28 => 30（给顶边留呼吸）
  transition: `color ${tokens.motion.duration.fast}ms ${tokens.motion.easing.enter}, background ${tokens.motion.duration.fast}ms ${tokens.motion.easing.enter}`,
  // 其余（padding/gap/cursor/fontSize/whiteSpace）不动
}}
```

> 效果：激活页签 = 白底 + 2px 主色顶边 + 顶部圆角，视觉上"钉在"内容区上方；未激活透明、hover 由 antd 默认 hover 给出（tab 项非 Menu，不加自定义 hover 类，保持简单）。
