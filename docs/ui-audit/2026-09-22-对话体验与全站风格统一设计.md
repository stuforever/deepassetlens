## 一、统一风格体系（一套风格，全站适用）

### 1.1 单一事实来源

- **视觉 token 唯一来源** `theme/tokens`：主色 / 圆角(8) / 间距(4 步进制) / 字阶 / 阴影；任何页面禁写裸色值裸尺寸。主题收敛为**单主题**（ADR D2 不变）。
- **组件规范表**（全站唯一档位，新页面只允许取档）：

| 组件 | 规范 |
|---|---|
| 下拉 Select | 宽度三档 sm=120/md=200/lg=320，表单内 100%；选项 >7 必带 `showSearch`；**统一 antd Select，原生 select 全站清零**（复刻域见 1.2） |
| 抽屉 | 三档：详情 400 / 表单 560 / 大编辑 720 |
| 弹窗 Modal | 两档：确认 448 / 表单 600 |
| 表格页 | 筛选条(固定项+「更多筛选」)+ 撑满表格 + 右详情抽屉；操作列 hover 显现，危险操作收「⋯」标红 |
| 表单 | 单列 ≤560px，标签左对齐 96px，吸底保存条 |
| 按钮 | 主操作唯一 primary，其余 default/text |
| 左栏 | 一律 232（token `siderWidth`），容器统一 antd `Layout.Sider` |

- **布局法则**（不变）：F 型动线 / 三栏语义固定 / composer 贴底居中 ≤720px / 首屏责任制 / 骨架尺寸统一。

### 1.2 两套风格并存的收口机制（迁移已完成，复刻纪律到期）

复刻验收已归档 → 启动**「复刻毕业」**：DT 复刻域不再是"一字不改"的保护区，按 §1.1 规范逐页收编（原生 select→antd、裸色→token、零散弹窗宽度→档位）。收编顺序见 §七。**自此全站只有一套风格定义，不允许第二套存在。**

## 二、主对话区设计（核心）

### 2.1 布局：无历史列表的单栏对话

```
┌─────────────────────────────────────────┐
│ 消息流（用户右气泡 / AI 左文）             │
│  · 查询结果表（可下载 CSV）               │
│  · 思维链折叠卡 / 追问 chips / 操作条      │
├─────────────────────────────────────────┤
│ 附件条：📚知识库 ▾ │ ⚡技能 ▾ │ 🤖模型 ▾ │ 🎭角色 ▾ │
│ ┌─────────────────────────────────┐     │
│ │ 输入问题…                  发送 │     │ ← composer 居中 ≤720px
│ └─────────────────────────────────┘     │
└─────────────────────────────────────────┘
```

- **无历史记录列表**（用户定调）：对话页就是当前会话；历史从 💬 图标面板进入（§六）。
- **新建对话页（首屏 `/`）**：中央 composer + 专家 Tab + **模板宫格**（见 2.2）+ 最近对话卡条 ×5。

### 2.2 八个问答模板（点击=回填，不直发）

新建对话页 composer 上方 2×4 宫格（选中专家 Tab 后显示对应模板）：

| 问数（数据探索）8 模板 | 私塾（教学）8 模板 |
|---|---|
| ① 数据概览：{主题}有多少？分布如何？ | ① 课文讲解：讲一讲{课文} |
| ② 明细查询：查{实体}的{条件}明细 | ② 出题练习：围绕{知识点}出 5 道题 |
| ③ 对比分析：{A}和{B}对比 | ③ 错题讲解：分析我的错题 |
| ④ 趋势/占比：{指标}按{维度}的占比 | ④ 学习计划：给我安排{主题}学习路径 |
| ⑤ 异常排查：{实体}有什么异常？ | ⑤ 学情解读：我最近学得怎么样？ |
| ⑥ 指标解读：{指标}含义与口径 | ⑥ 阅读伴读：陪我读{篇目} |
| ⑦ 血缘追溯：{资产}从哪来？ | ⑦ 知识问答：{知识点}是什么意思？ |
| ⑧ 自定义（空模板，聚焦输入框） | ⑧ 自定义 |

**交互铁律：点击模板 → 模板文案（含 {占位符}）填入 composer 并聚焦，用户改完自己点发送。任何情况下点击模板不直接发起请求。** 模板配置存前端常量文件（每专家 8 条），不发后端。

### 2.3 消息元素（保留项与用户点名保留项）

每条 AI 回答操作条：**复制 / 保存到笔记 / 下载 Markdown**（后两项用户点名保留）/ 点赞点踩（现有自评机制）。追问推荐 chips 保留（现机制）。查询结果表保留 thead/tbody 结构与 CSV 下载。

### 2.4 Composer 附件条（四个选择器，统一左到右）

| 选择器 | 内容 | 规则 |
|---|---|---|
| 📚 知识库 | 多选下拉，列出知识库名（**禁裸 UUID**） | 默认全选/跟随专家默认；选择随会话保持 |
| ⚡ 技能 | 单选下拉，**只列场景技能**；通用技能不出现（自动装配，§三） | 默认「自动」；选中即锁定该场景 |
| 🤖 模型 | 单选下拉，列出启用中的 LLM 连接（现有 `llm_connection_id` 入参直达） | 默认「默认模型」；记忆上次选择 |
| 🎭 角色 | 单选下拉，列出该专家的角色卡 | 私塾=现有个性化角色；问数=新增角色（§四） |

四选择器全部走 §1.1 下拉规范（md=200、showSearch 视数量）。选中态显示在附件条 chip 上，可随时改。

### 2.5 空态与首屏责任制

对话页空态 = 精简版模板宫格（4 条）+ 一句专家问候；首屏只干"发起对话"一件事。

### 2.6 H5 与桌面同体

- H5 对话页与桌面对话页**共用同一对话组件**（同消息渲染、同流式协议、同 composer 核心）；
- 区分仅靠后端 `source` 标记（现有机制：h5 走 `/h5/chat` 记 source=h5，桌面 `/e/{slug}/chat` 记 source=web）；
- H5 侧差异只在**壳**：底 Tab、语音键放大、拍照键——对话体本身零差异。H5 不显示附件条四选择器（移动端精简，用默认装配），长按消息出「保存笔记/下载」。

## 三、技能体系规划

### 3.1 二分法定案

| 类型 | 定义 | 用户可选？ | 归属现状 |
|---|---|---|---|
| **场景技能** | 绑定具体业务场景（有契约/模板/工作流步骤） | ✅ 技能下拉只列此类 | 私塾=全部场景技能；问数=部分（金标直通/计数等） |
| **通用技能** | 基础能力（实体定位/取数/SQL 派生/澄清） | ❌ 不出现，由契约路由自动装配 | 问数主体 |

用户的判断成立：**通用技能不让选，只让选场景的**。实现：技能注册表加 `type: scenario|general` 字段（技能管理页同步加此列与筛选），对话技能下拉过滤 `type=scenario AND expert=当前专家`。

### 3.2 问数场景技能扩充方向（补齐"大多是通用"的短板）

按 8 模板反推，问数应具备的场景技能集（每个=契约+模板牢笼）：数据概览 / 明细查询 / 对比分析 / 趋势占比 / 异常排查 / 血缘追溯 / 指标解读 / 客户巡访（已有）。新建走现有「技能管理」页，骨架同私塾场景技能。

## 四、角色体系规划

- **私塾**：现有个性化角色（学习风格/声调等槽位）原样保留，角色下拉直接列；
- **问数**：**追加个性化角色能力**——后端挂载点已存在（expert card 的 `system_prompt` 槽，expert_config.py L36/L70）。预置 3 张角色卡：
  1. **默认分析师**（现状等价，口径严谨、四段式）；
  2. **业务白话型**（少术语、多举例、结论先行）；
  3. **技术 detail 型**（附 SQL/口径/血缘细节）。
  角色卡管理：设置中心「角色卡」页对 wenshu 开放编辑（现仅 sishu 可见该页——设置注册表加专家维度即可）。
- 角色与技能正交：角色改"怎么说"，技能改"干什么"；两者可同时选。

## 十二、思考过程与流式输出统一（一套组件，内容层个性化）

### 12.1 业界常规做法（ChatGPT / Claude / DeepSeek / Gemini 一致）

- **思维链 UI 形态全平台统一**：一个折叠组件——生成中显示状态行（"思考中…"/"正在调用 XX 工具"），完成后折叠为「已思考 Xs」一行，点击展开看步骤；**没有任何产品按智能体分叉思维链 UI**；
- **个性化在内容层不在组件层**：不同智能体/模型的差异体现在步骤**文案与工具名**（o1 显示推理摘要、DeepSeek 显示完整思维链），骨架组件同一个；
- **流式输出统一**：打字机节奏、Markdown 渲染、代码块、表格全站一套渲染器；
- 原理：思维链是"机器过程"，用户预期是稳定可预测的（在哪找、怎么展开）；智能体的个性由**角色 persona（语气/文风）**承载，不由 UI 分叉承载。

### 12.2 本项目调整方向

现状：问数 ThinkStream 已相当精细（状态行「小探正在推理·第 N 轮」+ 工具中文名·参数摘要 + 完成耗时闪示 + 折叠步骤卡），私塾另一套简单 Loading——**以问数为标杆收编**：

| 决策 | 方案 |
|---|---|
| **组件唯一** | 全站一个 `<ThinkingChain>`（以现 ThinkStream 为底改通用）；私塾/问数/h5 共用，删除私塾独立实现 |
| **个性化走配置** | 专家卡加 `thinking_texts` 文案映射表：`{agentName:"小探"/"小塾", phases:{...}, toolNames:{...}}`；私塾步骤文案（读课文/出题/判错）与问数（定位/取数/SQL）不同，**骨架零分叉** |
| **流式渲染统一** | 打字机节奏/光标/Markdown/表格（SqlResultTable）一套渲染器；私塾答题卡是**内容类型**差异（registerRenderer 机制已有），不是流式机制差异 |
| **展示策略统一** | 生成中：状态行单行可见（不打断阅读）；完成后：折叠「已思考 Xs · N 步」；错误步骤标红；h5 同组件窄屏适配 |
| **证据胶囊** | 思考链与 §11.2 的 EvidenceCapsule 串联：思考链讲"怎么想的"，证据胶囊讲"依据什么"，各司其位 |

### 12.3 实施落位

- 步①（对话核心）新增任务：ThinkingChain 通用化 + 专家文案映射表 + 私塾切换；
- 步⓪（回归修复）新增任务：删两对话页「审计模拟」按钮；前台 ContractCardsPanel 下线（EvidenceCapsule 未就绪前先整体折叠隐藏，宁缺毋滥）；
- 引擎台「路由模拟」Tab 与运行观测「契约轨迹回放」列入步⑥（后台与独立页）。

### 12.4 分层原则（统一什么 vs 特色什么）

| 统一（全站一套，禁分叉） | 特色（专家各自配置） |
|---|---|
| 字体族/字阶/行高/字重 | 专家名（小探/小塾/……） |
| 颜色四级层级 | 步骤文案、工具中文名 |
| 间距 4 步进 | 欢迎语、推荐问法、空态插画文案 |
| 强调规则（加粗/斜体/code） | 角色语气与回答文风 |
| 组件骨架（ThinkingChain/composer/表格/抽屉） | 空间色点缀（仅组图标/激活态/页头 3px 条） |

## 附录 A · 全站排版规范（Typography Spec，思考链与全部页面共用）

> 定调来源：用户 2026-09-22「思考界面展示风格保持一致，文字、排版、间距、斜体、加粗等统一，内容可有各自特色」。
> 本附录为**全站唯一排版标准**，实施时落进 `theme/tokens` + 全局 CSS 变量，组件只引用不自定义。

### A.1 字体族（2 个）

| 用途 | 字族 |
|---|---|
| 正文/界面 | `-apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`（antd 默认栈，直接用） |
| 机器概念（SQL/表名/字段名/参数值/路径/错误码/耗时数字） | `"SF Mono", Consolas, "Courier New", monospace` |

### A.2 字阶（5 级，全站封顶）

| 级 | 字号/行高 | 字重 | 用途 |
|---|---|---|---|
| T1 | 20/28 | 600 | 页头标题 |
| T2 | 16/24 | 600 | 区块标题、抽屉标题 |
| T3 | 14/22 | 400 | **正文基准**（AI 回答、表单、表格） |
| T4 | 12/20 | 400 | 辅助说明、时间戳、耗时、参数摘要 |
| T5 | 12/18 | 500 | 胶囊/标签/chips |

### A.3 颜色层级（4 级文字 + 语义色）

| 级 | 值（单主题） | 用途 |
|---|---|---|
| 主文 | rgba(0,0,0,.88) | 正文、标题 |
| 次文 | rgba(0,0,0,.65) | 状态行、说明、步骤名 |
| 弱化 | rgba(0,0,0,.45) | 时间戳、耗时、占位符、参数摘要 |
| 禁用 | rgba(0,0,0,.25) | 不可点态 |
| 语义 | 成功/警告/错误/链接 全部走 antd token，禁自调色 | — |

### A.4 强调规则（本规范的核心裁决）

| 手段 | 规则 |
|---|---|
| **加粗** | 仅用于：结论句关键数值、字段名、操作后果警示。**一段 ≤3 处，禁整句/整段加粗** |
| *斜体* | **中文全面禁用**（中文斜体是算法伪斜体，视觉脏）；仅允许西文术语/书刊名场景 |
| `等宽` | 一切"机器概念"：SQL 关键字、表/字段名、参数、路径、错误码、耗时与轮次数字 |
| 下划线 | 仅链接 hover；**禁止**用下划线做强调 |
| 删除线 | 仅表示"已废弃的旧值" |
| 颜色强调 | 只允许用语义色；禁正文里插彩色文字 |

### A.5 间距（4px 步进，全站封顶 6 档）

`4 / 8 / 12 / 16 / 24 / 32`——消息气泡间距 16、段落间距 12、卡片内边距 16、区块间距 24、页边距 24。组件内禁止出现非 4 倍数间距。

### A.6 数字与时间格式

- 数字：千分位（12,345）；表格内右对齐 + 等宽数字；
- 耗时：统一 `8.2s` 一位小数；轮次「第 N 轮」；
- 时间：24h 内相对化（3 分钟前），更早显示 `MM-DD HH:mm`；
- 单位紧跟数字不空格（210 行、5 户）。

### A.7 思维链 ThinkingChain 排版规格（落 A.1-A.6 的实例）

| 元素 | 规格 |
|---|---|
| 生成中状态行 | T3 次文色 + 16px spinner；工具中文名=次文正文，参数摘要=T4 弱化色等宽（截断 36 字符沿用现状） |
| 完成折叠行 | 「已思考 8.2s · 5 步 ›」T4 弱化色，整行可点，hover 次文色 |
| 展开步骤卡 | 步骤名 T4 次文 500；耗时右对齐等宽弱化色；步骤间距 8，卡片内边距 12，左侧 2px 导轨线（次文色 20% 透明） |
| 错误步骤 | 红色 ✕ 图标 + 次文色文字；**禁整行红底红字** |
| 专家个性 | 仅换 `agentName` 与步骤文案（专家卡 `thinking_texts` 配置），上述规格一字不改 |

### A.8 AI 回答正文排版

- 正文 T3，行高 22；标题最多用到 T2（回答内不建深层级）；
- 列表缩进 16，条目间距 4；表格沿用 SqlResultTable 统一样式（表头 T4 次文 500、单元格 T3、数字右对齐等宽）；
- 代码块：等宽 + 灰底 #f6f8fa + 圆角 8 + 内边距 12；
- 结论/发现/风险/建议四段式保留（wenshu 契约要求），段标题加粗（全段唯一允许的加粗位）。

**验收口径**：Playwright 截图对拍时，问数/私塾/h5 三端各取一条含思考链的回答，逐元素核 A.7 规格；全站 grep 禁出现 `font-style: italic`（中文区）、非 A.2 字阶、非 4 倍间距。

## 十三、左面板三态、统一宽度与右栏语义（用户定调：不能半拉子，面板大小统一，右侧空白要有用途）

### 13.1 左侧面板三态（收起 / 浮层 / 钉住）

| 态 | 行为 | 触发 |
|---|---|---|
| 收起 | 仅剩 48px 图标条 | 点外部 / Esc / 再点同图标 |
| 浮层 | 面板滑出**浮在主区上**（带阴影，不挤主区） | 点图标（默认态） |
| 钉住 📌 | 面板常驻，主区右移让位 | 面板头部钉住按钮；状态记 localStorage，全站记住 |

三态对 💬对话 / 🗂管理台 / ⚙设置 三个面板**完全一致**——同一套壳组件，只是内容不同；不存在"对话能钉、管理台不能钉"的半拉子形态。

### 13.2 面板宽度统一：一律 400px

- 三个面板**同宽 400**（与详情抽屉档一致，§1.1）；
- 管理台 16+ 项在 400 内**双列网格**平铺（每格 ~180：图标+名称）；对话历史/设置分区**单列**；
- 面板内部滚动，高度撑满；禁出现第三个宽度。

### 13.3 右栏语义固定：上下文与产物（"右侧空白"的用途定案）

三栏语义固定为全站法则：**左=导航，中=主内容，右=上下文/产物**。右侧不留无名空白。

**对话页右栏**（默认收起为 40px 细条竖排图标，点击展开 320px 面板，可钉住）：

```
│ ▌📎 依据      ← 证据列表（EvidenceCapsule 的展开位：引用了哪些表/文档/知识库）
│ ▌⚙ 本场配置   ← 当前知识库/技能/模型/角色的选择态（附件条的镜像详情，可改）
│ ▌⬇ 产物       ← 本对话产物统一下载区：
│                 查询结果 CSV / 回答 Markdown / 已存笔记列表
```

- 「产物」区回应"能下载？"——**能**：每次查询的结果表 CSV、每条回答的 md、保存的笔记，在此集中列出随时下载（与 §二.3 消息操作条的"保存/下载"是一对：消息上操作，产物区归集）；
- 画布页右栏 = 属性面板（已有规范 320）；表格页右栏 = 详情抽屉 400（已有规范）；设置页无右栏（单列表单居中）——**每页右栏有且只有一种语义**；
- 右栏钉住态主区 composer 仍居中于剩余宽度（≤720 上限不变）。

### 13.4 落位

- 步③（导航重构）：面板三态 + 统一 400 宽度一并实施；
- 步①（对话核心）：右栏细条 + 三面板（依据/本场配置/产物）；
- 验收加两条：三面板宽度实测相等；右栏默认收起、展开/钉住/收起三态截图对拍。
