# 示例库运营 SOP（S4，一页文档）

> 适用：示例库（`/qa-examples`）日常运营。目标：让「命中率」成为准确率的**先行指标**——
> 命中率低 = 该问题家族缺少已验证示例，应先于用户差评发现并补录。
>
> 数据来源：示例库管理页 `/qa-examples`（累计命中 / **30 天命中** 两列 + 行操作「相似预览」top-5 带相似度）。

---

## 1. 指标口径

| 指标 | 口径 | 用途 |
|---|---|---|
| 累计命中 `hit_count` | 示例被注入 SystemMessage 的累计次数（life-time） | 长期热点 |
| **30 天命中** `hit_count_30d` | 近 30 天 examples.injected 命中事件数（`kg_example_hit_logs`） | 近期趋势、运营主指标 |
| 相似度 `score` | Qdrant 向量相似度（`TUPU_EXAMPLE_SIM_THRESHOLD`，默认 **0.75**） | 相似预览 / 阈值调优 |

> 口径说明：命中事件在每次问答把示例注入参考块时落库（`bump_hit_count`，去重后写
> `kg_example_hit_logs` + 累计计数）；精确匹配（sim=1.0）直通优先，防向量抖动。

---

## 2. 月度回顾流程（每月第 1 个工作日，约 30 分钟）

1. **打开 `/qa-examples`**，按「30 天命中」列从低到高排序（当前列表按创建时间倒序，可用关键词+状态过滤缩小范围）。
2. **识别低命中高频问题**：
   - 30 天命中 = 0 的 `user_confirmed` / `golden` 示例：可能已过时（数据口径变化、用户不再问）→ 复核是否停用（`status=disabled`）。
   - 近期客服/答疑里反复出现但示例库**没有**的问题：在管理页**新增手工示例**（问题 + 验证 SQL，`example_type=manual`），DB + Qdrant 向量点同步入库。
   - 现有示例疑似与多条相似：点行操作「**相似**」，看 top-5 相似问题及相似度——相似度 ≥0.75 的重叠可考虑合并（避免示例集膨胀导致检索互相干扰）。
3. **审核队列**：`status=review`（用户 👎 + 修正 SQL 自动进入）逐条复核 → 「通过」（`enabled`）或「删除」。
4. **阈值调优（可选）**：若发现示例被明显误召回（相似度低却命中），上调 `TUPU_EXAMPLE_SIM_THRESHOLD`
   （如 0.8）观察一周；反之若召回过窄，下调。环境变量改后**无需重启**（每次检索读取）。
5. **记录**：本次回顾补录/停用/合并的条目数，写入发布清单或群周报。

---

## 3. 关键操作速查（管理页）

| 操作 | 入口 | 说明 |
|---|---|---|
| 补录示例 | 「新增手工示例」Drawer | 问题原文 + 验证 SQL 必填；路由/引擎/类型按实际 |
| 相似排查 | 行操作「相似」 | Drawer 内 top-5 相似问题 + 相似度（≥0.75 绿色标） |
| 启停 | 行操作「停用/启用」 | 停用后不再参与示例召回 |
| 审核 | status=review 行「通过」 | 用户修正示例，复核后启用 |
| 删除 | 行操作「删除」 | 同步删 DB 行 + Qdrant 点 + 命中事件 |

---

## 4. 示例（一期运营场景）

场景：本月高频问题「统计各供电局上月的用电客户数」多次被问，但示例库只有「统计用电客户总数」。

1. 在管理页搜索确认：无 `question_norm` 归一化后的精确示例（`TUPU_EXAMPLE_SIM_THRESHOLD=0.75` 未召回该家族）。
2. 新增手工示例：问题 = 「统计各供电局上月的用电客户数」，SQL = `SELECT supply_bureau, COUNT(*) ... GROUP BY supply_bureau`。
3. 次月回顾：该示例「30 天命中」>0 且问题家族准确率提升 → 命中率作为先行指标生效。
4. 若「上月」类追问未命中：`question_norm` 精确匹配直通会以 sim=1.0 命中原文；带标点/空格差异由规范化比较兜底。
