# DeepAssetLens 前端组件级规格（按图施工版）

- 日期：2026-08-17 ｜ 性质：**纯设计规格，不含代码修改**
- 配套：《前端界面美化重设计_20260817.md》（下称「母设计」）
- 精度：所有尺寸给 px、所有颜色/间距/圆角给 token 名、所有状态给全、所有动效给时长+曲线
- 单位约定：`s1~s7` = `tokens.space`（4/8/12/16/20/24/32）；颜色均为 `tokens.colors.*`；圆角均为 `tokens.radius.*`

## 0. 新增 Token 精确值（施工第一步，其余组件只引用）

### 0.1 elevation（写入 `tokens.ts` + `index.css` 同名变量）

| token | 值 | CSS 变量 |
|---|---|---|
| `elevation.s1` | `0 1px 2px rgba(15,23,42,.04), 0 1px 3px rgba(15,23,42,.06)` | `--shadow-s1` |
| `elevation.s2` | `0 4px 12px rgba(15,23,42,.08), 0 2px 4px rgba(15,23,42,.04)` | `--shadow-s2` |
| `elevation.s3` | `0 12px 32px rgba(15,23,42,.14), 0 4px 8px rgba(15,23,42,.06)` | `--shadow-s3` |

### 0.2 品牌渐变

| token | 值 |
|---|---|
| `brand.gradient` | `linear-gradient(135deg, #2563EB 0%, #7C3AED 100%)` |
| `brand.gradientHover` | `linear-gradient(135deg, #1D4ED8 0%, #6D28D9 100%)` |

### 0.3 图表色板（chart categorical，循环取用）

```text
chart.1 #2563EB   chart.2 #7C3AED   chart.3 #0891B2   chart.4 #059669
chart.5 #D97706   chart.6 #DC2626   chart.7 #64748B   chart.8 #BE185D
```

### 0.4 动效

| token | 值 |
|---|---|
| `motion.fast` | `120ms` |
| `motion.base` | `200ms` |
| `motion.slow` | `320ms` |
| `motion.easeEnter` | `cubic-bezier(.2,.8,.2,1)` |
| `motion.easeExit` | `cubic-bezier(.4,0,.6,1)` |

### 0.5 字号补充：`fontSize.display = 28`（仅落地页主视觉）

### 0.6 焦点环（全局）

`:focus-visible { outline: 2px solid var(--color-primary); outline-offset: 2px; }`，覆盖 antd 默认偏淡的焦点样式。

### 0.7 z-index 刻度（自定义层全部 < 1000，避开 antd 弹层层）

| 层 | z | 用途 |
|---|---|---|
| sticky 表头 | 5 | ResultTable / 管理页表格 |
| ScrollToBottom | 20 | 对话页回底按钮 |
| 画布浮层（工具条/图例/小地图） | 30 | FloatingToolbar / Legend / Minimap |
| TopBar | 100 | 顶栏玻璃层 |

### 0.8 图标尺寸规约

菜单/按钮内 **14px**；表格/胶囊/行内 **12px**；空态 **40px**；错误态 **28px**；会话列表 **12px**；关闭图标 **10px**。

## 5. 全局通用规范

1. **流式路径零阴影/filter**：凡 SSE/thinkStream 更新区域（C16/C17 运行态/C19 表体），动画仅 opacity/transform。
2. **`prefers-reduced-motion`**：全局禁用 0.4/0.7 定义的所有动画（含脉冲、shimmer、光标闪烁退化为静态）。
3. **焦点环**：全站 `:focus-visible` 统一 0.6 规格，覆盖 antd 默认。
4. **数字一律 `tabular-nums`**：统计、计数、表格数字列、分页。
5. **图标一律 `@ant-design/icons`**，尺寸按 0.8 规约，不引新图标库。
6. **token 唯一来源**：本规格中所有值施工时落到 `tokens.ts` / `index.css` / antd `components` token，组件内零硬编码。
