### smart_skill_pipeline 例外依据（与 duckdb_engine 900 同理）

1. **结构原子性**：`_invoke_skill` 为单函数（L141-1660）：setup + 20 个嵌套助手 + ~800 行内部调度链；助手闭包 `db`/`_pick_script_assistant_llm` 等局部变量，dedent 会产生 NameError/循环导入；拆至 <800 需参数化重构，违背「零行为变更」。
2. **既有断链（拆分前即存在）**：`from .smart_apps import generate_smart_join_candidates, CONFIDENCE_THRESHOLD` 中 `app.api.smart_apps` **不存在**（git HEAD 亦无），本模块**当前无法 import**；`smart_skills.py`（唯一 import 方）亦无任何引用者——整条为死代码链，pytest 359 不覆盖。
3. **处置**：待专项（补 `smart_apps` 模块 + `_invoke_skill` 参数化重构）再拆；当前不拆不构成发布风险（无运行时引用）。
