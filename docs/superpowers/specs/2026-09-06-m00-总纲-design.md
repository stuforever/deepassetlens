## 一、工程定位

**DeepAssetLens（tupu 平台）**：企业数据资产的深度探查与可控问数平台。五大能力域一体：

1. **图谱建模**——概念四区体系（L1-L4）、实体与关系、主数据/活动数据、血缘、Neo4j 图谱引擎；
2. **数据资产**——数据源、来源表（主数据表/业务表/参考表）、字段导入、实体映射与 API 编排；
3. **语义管理**——标准语义词条、同义词、停用词、标准字典、时间/意图/炸开归一化、多集合向量化；
4. **能力指标**——指标中心（原子/派生/维度绑定/版本/审计/使用统计 12 张表）；
5. **问数智能体**——受控问数全链路（路由/契约/守卫/Agent 装配/金标直通/多引擎执行/流式交付）。

支撑面：系统配置（LLM 连接/Doris 配置/数据源配置）、认证权限（Authentik OIDC/RBAC/ACL）、技能工作流（v2 smart skills/管道/runs）、调度后台作业、知识库、工单、治理观测、测试质量体系。

**非目标**：通用聊天机器人；无守卫的自由 SQL 执行；代码执行类能力（shell/沙箱为框架红线，见 M17）。

## 二、五条设计铁律（全模块通用）

1. **受控优先**：路由=权限边界（纯规则确定性，不交给采样）；每问有契约（允许集）；执行前过守卫闸门。指标/图谱/资产等管理域同理——写操作有版本与审计（kg_metric_audit_logs/kg_metric_versions）。
2. **框架原生件优先于自研**：Agent 循环用 deepagents 骨架，自研只做业务锁（契约/守卫/路由）；标准库/已有依赖优先（AGENTS.md 决策优先级六条）。
3. **护栏先行再点火**：能力开关总闸+白名单+契约声明+管理页可视四件套，缺一不启用（红线可逐条翻案，全部登记）。
4. **数据驱动**：SKILL.md 剧本唯一事实源；金标锚定；概念/指标/语义全部数据化配置；能力开关全配置化（改配置=缓存键变=重建生效）。
5. **YAGNI 命中即止**：不做想象中的需求；闸后项登记触发条件，不预支。
