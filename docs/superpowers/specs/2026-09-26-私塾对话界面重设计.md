> 2026-09-26 · 用户定调：私塾界面"现在都挤到一块了"——**内容元素暂时全部保留**，只重排版式；**色素、风格与问数保持一致、与主色搭配**，做好看。
> 范围：`/e/sishu/chat` 对话页（欢迎态 + 消息态 + 右栏 ContextRail）。纯前端、零新依赖、零新接口、不改后端。
> 约束：所有 `data-testid` 保持不变（sishu-space-grid / sishu-grid-* / space-color-bar / dal-stat-capsule / dal-suggest-card / expert-composer），既有 e2e 不断。

## 一、现状诊断：为什么"挤到一块"

欢迎页（无消息态）是一个 `justify-content:center` 的单列 flex 容器，**九个视觉块无分组、无层次地垂直堆叠**：

```
主视觉(渐变标题+tagline) → 动态数裸文字 → 统计胶囊×2 → composer
→ 7宫格(auto-fill minmax140px，720px 内挤成 4+3) → 建议卡×4(2×2)
```

四处具体问题：

1. **无分区**："问学"（composer/建议卡）与"功能导航"（7 宫格）两种性质的内容首尾相接，视觉权重一样，互相争抢；
2. **语义重复**：hero 下裸文字"今日 N 题待复习，已连续 M 天"与下方两枚统计胶囊（待复习/连续学习）是**同一份数据渲染两遍**，且样式一裸一卡，显得乱；
3. **色彩越位**：连续学习胶囊图标用 AI 紫 `#7C3AED`，与私塾空间色琥珀 `#D97706` 同屏打架；宫格、动态数、胶囊三处琥珀用法不一致；
4. **挤压式居中**：`justify-content:center` 让内容在视口中段互相挤兑，小屏直接溢出；宫格 `auto-fill` 列数随宽度漂移，4+3 断行不规整。

## 二、设计总则

1. **元素零增减**：现有全部元素保留（清单见 §三），只做分区、排序、间距、色彩、规整化；
2. **结构对齐问数**：Zone A（问学区）与问数首页 1:1 同构——主视觉 → 统计胶囊 → composer → 建议卡 2×2；私塾特有内容收进 Zone B（功能区），视觉权重降级；
3. **色彩纪律（与主色搭配）**：
   - **主蓝 `#2563EB`**＝动作色：发送钮渐变、建议卡图标、focus 环、链接、滚动到底钮（同问数）；
   - **琥珀 `#D97706`**＝私塾身份色，**且只用于**：顶部 3px 色条、宫格图标、动态 chip、Zone B 区标题装饰、两枚学习胶囊的图标与数字；
   - **AI 紫 `#7C3AED` 在私塾页退场**：连续学习胶囊图标/数字由紫改琥珀（同一空间单一强调色；渐变标题的紫是平台统一品牌渐变，保留）；
   - 其余全部走 tokens 中性色（--text-primary/secondary/tertiary、--bg-content、border、s1/s2 阴影），与问数完全一致；
4. **间距节奏**：8px 基准；Zone 间隔 28px，区内块间距 16-24px；整页 `max-width: min(100%, max(720px, 60vw))`（CONTENT_WIDTH 现状保留）；
5. **容器修正**：`justify-content:center` → `flex-start` + 首块 `margin-top:auto`、末块 `margin-bottom:auto`（内容少时自然居中、多时顶部对齐可滚动，不再挤压）。

## 七、验收口径

1. 元素存在性：§三清单 9 项全部在屏（testid 不变，既有 e2e 全绿）；
2. Playwright 截图对拍：欢迎态 1440/1024/768 三档宽度各一张——Zone A/B 分区清晰、宫格 4 列规整、无紫元素（除渐变标题）、无重叠溢出；

4. 1280×800 视口下整页无垂直挤压（内容可滚动、首屏可见 composer）；
5. 问数页 `/e/wenshu/chat` 零变化（对照截图）。
