# M19 守卫与安全体系 设计规格（金标准）

> 套件：DeepAssetLens 全量金标准 M19（总纲见 m00）。as-if-greenfield 视角。
> 取证基线：HEAD `0d67f4c`（2026-09-06）。本模块改动须先过两技能管线并回写本 spec 状态。

## 一、模块定位

问数智能体域的**执行拦截层**：SkillPolicyMiddleware「牢笼」（工具调用前/后十项硬校验，模型只能在契约边界内判断）、SQL 模板守卫（严格派生校验）、定位类工具预算闸门与同参去重（P0 死循环防线）、纠错指引体系（G2）、**HITL 人审中断**（S5 v2）、守卫配置中心（guard_config）与试探单（guard_probes）。**永远不回退到不受控自由问答**是铁律。

**边界**：契约裁决数据（allowed/forbidden/templates/engine）产地在 M18；守卫配置版本进 Agent 缓存键 #g 成分（M17 联动）；SQL 执行归 M21；金标直通豁免归 M20。

## 三、十项硬校验（设计 §6.1，skill_policy 文件头 L1-14）

1. 工具是否在 QueryContract.allowed_tools；
2. 是否调用禁用工具（task/write_file/edit_file/execute/grep/glob——ABSOLUTE_FORBIDDEN）；
3. 引擎锁定一致性（锁定后其他引擎查询工具立即失效）；
4. SQL 是否严格派生自已批准模板（template_guard）；
5. stop_when 命中后继续检索（终端步骤禁止再查）；
6. 数据工具未经 batch_entity_source_mode 确认引擎（引擎优先）；
（+运行期派生项：定位预算/同参去重/纠错上限/HITL 触发——见 §四-§六）

**违反处置**：第一次拒绝调用并返回「允许的下一步」（REJECT_MARKER「SkillPolicy·拒绝」）；第二次终止本轮（BLOCK_MARKER「SkillPolicy·已阻断」，MAX_VIOLATIONS=2）；**永远不回退自由问答**。SSE 事件：policy.rejected/engine.selected/stop.reached/template.bound/policy.degraded——前端据帧渲染「系统阻止了不合规操作」。

## 四、纠错指引体系（G2，含 P0-COUNT 防线）

**可纠错五类**（_CORRECTABLE_CLASSES）：TABLE_MISSING/CATALOG_MISSING/SYNTAX/TIMEOUT/AGGREGATE_DEGRADED——ToolMessage 附 correction 结构化指引（_CORRECTION_GUIDES 五条文——每类一句话+下一步指令）；**上限 2 次**（_CORRECTION_LIMIT），AGGREGATE_DEGRADED 放宽 **3**（非死循环是模型方差，多一次显著收敛）；超限直接终止出失败卡（P0 死循环教训）。**SECURITY_VALIDATION 禁重试**（层间裁决不一致/安全底座拒绝——模型无错不可自愈，直接基于已获信息出结论）。

**定位预算闸门**（P0-COUNT 修复，2026-09-05 实证：generic COUNT 题同参 search×28+batch×12 交替 163s 打结）：
- **L1 同参去重**：纯检索类四件（search_entities/validate_l2/fetch_subgraph/fetch_l1_l2_tree）同工具同参数第二次直接拒（确定性同参必同果）；**状态机推进工具不去重**（batch_entity_source_mode/get_entity_source_mode——逐实体确认推进 confirmed_engines 合法同壳）；
- **L2 总预算**：定位类六件累计超阈值拒绝并注入「立即前进」强指令——generic 默认 8（TUPU_LOCATE_BUDGET）、场景 14（TUPU_LOCATE_BUDGET_SCENARIO）；数据工具不受影响。

## 五、HITL 人审中断（S5 v2）

- **触发集**：TABLE_MISSING/CATALOG_MISSING（唯一许可降级的两类）——由「自动降级一次」升级为 **interrupt 请求人审**；SYNTAX 仍走自动纠错（无定位语义）；
- **机制**：_HITL_INTERRUPTS 注册表（interrupt_id→asyncio.Future）在 agent 循环内 await；M16 /chat/freeplan/resume 端点按 interrupt_id 解析（resolve_hitl_interrupt，approve 授予一次定位许可）；**超时 180s 视为拒绝**（TUPU_HITL_TIMEOUT——继续自动纠错/失败卡）；
- 降级工具集（批1 遗产）：search_entities/list_tables 只读重定位——S5 后收敛为人审授权路径。

## 六、SQL 模板守卫（template_guard）

**严格派生校验**（validate_against_template→_strict_derived_from_template）：
- **结构**：SELECT-only（_is_select_only）/无 UNION（_contains_union）/表集合 ⊆ 模板表集合（extract_tables）/无未渲染占位符（has_unrendered_params）；
- **WHERE 合取剪枝**：模板 WHERE 合取集 ⊇ 候选 WHERE 合取集（候选只能**删条件**不能加新谓词——_all_where_conjuncts/_prune_where_conjuncts，sqlglot AST 级）；
- **指纹**：fingerprint/canonicalize_sql（方言规整）/structural_fingerprint（结构指纹——金标相似度比对消费，M20 联动）；
- render_template（参数渲染）/template_id_components（"skill:relpath" 拆分——与 M18 template_ids 同构）/resolve_entity_aliases。

## 七、守卫配置中心与试探单

**guard_config**：守卫 policies（enabled/mode——warn/block 等模式位）/get_version（**进 Agent 缓存键 #g**）/guard_enabled(guard_id, sub_id)/record_event（verdict 裁决记录）/update_guard/reset_defaults/cleanup_old_events(30d)。
**guard_probes**：六类守卫各配探针（_probe_sql_safety/_probe_template/_probe_engine_lock/_probe_output/_probe_capability/_probe_approval_track）——前端试探单按钮的后端（探针主动打一次违规用例验证守卫仍拦）。
**审批轨**（approval_track，批13-V）：守卫族之一（人审配置面），版本入缓存键。
**API**：PATCH /{guard_id}（confirm 二次确认）/POST /{guard_id}/probe/GET /events/POST /reset-defaults——与能力开关 API 同构（M17）。

## 八、设计原则（本模块特有）

1. **永不回退自由问答**：拦截失败的唯一出口是终止本轮出失败卡——不存在「守卫关了就放开」的暗路径；
2. **两次违规则终止**：第一次教学式拒绝（告知允许下一步），第二次终止——模型自我修正窗口有界；
3. **纠错有上限有指引**：五类可纠错结构化指引+计数闸门（2/3 上限）；SECURITY_VALIDATION 禁重试（裁决不一致不可自愈）；
4. **定位有预算**：纯检索同参去重+总量闸门——死循环防线（P0 实证驱动）；
5. **人审只许两类**：TABLE/CATALOG_MISSING 才配走人审（唯一许可降级），其余自动路径——人审稀缺资源不被滥用；
6. **守卫可探可审**：每守卫配探针（试探单）+事件带 verdict——拦截不是黑盒。

## 九、验收标准

1. 十项校验：逐项桩触发（allowed 外工具/禁用件/引擎不一致/非模板 SQL/终端后再查/未确认引擎）全被拒；
2. 纠错：TABLE_MISSING 第一次拒绝+指引→修正重试成功；连续 3 次同类→终止失败卡；AGGREGATE_DEGRADED 上限 3；
3. 定位预算：同参 search_entities 第二次直接拒；累计超 8（generic）注入「立即前进」；batch 状态机同壳参数不去重；
4. HITL：TABLE_MISSING 触发 interrupt→resume approve 授予定位许可续跑；超时 180s 拒绝；
5. 模板守卫：派生合法（删 WHERE 条件）放行；加新谓词/UNION/非 SELECT/占位符残留全拒；
6. 守卫 PATCH 版本+1→Agent 缓存键变化（M17 联测）；试探单六类全 ok=True；事件 verdict 落表；
7. SSE 事件五类前端渲染（M16 联测）。
