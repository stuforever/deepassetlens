# M10 指标中心 设计规格（金标准）

> 套件：DeepAssetLens 全量金标准 M10（总纲见 m00）。as-if-greenfield 视角。
> 取证基线：HEAD `0d67f4c`（2026-09-06）。本模块改动须先过两技能管线并回写本 spec 状态。

## 一、模块定位

能力指标域：**指标全生命周期管理**——指标主档（业务口径/技术口径双轨）、原子指标（事实表+聚合定义）、派生指标（DSL/基础指标）、别名加权、维度绑定（含 join 路由）、过滤白名单（含算子白名单）、依赖图、**版本快照+审批流+回滚**、审计日志、使用统计、问数查询日志。

**边界**：MetricQueryLog 由问数链路写入（M16-M21）、金标种子读取（M20）、观测消费（M22）——本模块定义表与查询面；维度绑定的 join 路由执行在 M21。

## 三、指标主档与状态机（核心语义）

**kg_metrics**（L636-666）：metric_code unique / metric_name(_en) / **metric_type（atomic|derived）** / domain / metric_level / metric_unit / metric_subject / stat_grain / **business_caliber + business_owner + business_dept + requester_user（业务口径轨）** / **tech_caliber + dev_owner（技术口径轨）** / search_text / similarity_threshold / **status（默认 draft）** / owner_user / reviewer_user / manager_owner / **version_current** / enabled。

**审批状态机**（21 端点工作流组）：
```
draft →（submit）→ pending_review →（approve）→ approved →（publish）→ published
                                      ↘（reject）→ draft（附原因）
published →（rollback {version}）→ 恢复指定版本快照
```
每次 publish 产 **MetricVersion**（version/status/snapshot_json/created_by）快照；**MetricAuditLog**（action/before_json/after_json/operator）记录全操作前后态。

## 五、观测子模型（3 表）

- **MetricUsageStat**：query_fingerprint（64 位查询指纹）/hit_count/last_hit_at——按指纹聚合使用频次（热度排序）；
- **MetricQueryLog**：run_id/trace_id/user_query/intent/matched_metric_id+code/**mql_json/executed_sql/params_json**/data_source_id/query_status/error_msg/duration_ms——问数全量查询日志（**金标种子数据源**：M20 seed_golden 过滤 query_status=="success"）；
- 血缘端点（GET /metrics/{id}/lineage）：由 MetricDep 图计算（M13/前端 MetricLineageTab 渲染）。

## 八、设计原则（本模块特有）

1. **双口径轨分离**：business_caliber（业务侧填）与 tech_caliber（开发侧填）独立字段+独立 owner——口径对账以此为准；
2. **发布即快照**：published 状态永远可追溯到某版本 snapshot_json——回滚=恢复快照（无增量反向操作）；
3. **白名单是安全边界**：MetricFilterWhitelist 的字段+算子双白名单是问数过滤的**唯一放行面**（M19 守卫消费）——加白名单=扩大攻击面，须走审批；
4. **子资源整体替换**：7 个子资源 PUT 均为整组替换语义（前端整表编辑保存）；
5. **指纹统计**：使用统计按 query_fingerprint 聚合（同构查询合并计数），不逐条堆日志。

## 九、验收标准

1. 状态机全链：draft→submit→approve→publish（产版本快照+审计前后态）；reject 回 draft；rollback 恢复历史版本内容一致；
2. 原子/派生定义：atom 的 agg_func/measure/time 字段齐全；derived DSL 与 base_metric 两模式均可存取；
3. 白名单：字段+算子 JSON 存取完整（与 M19 守卫联测：白名单外过滤被拒）；
4. 维度绑定：join_route_json 状态流转可查；
5. 版本/审计：任意操作可回放（audit before/after 对）；版本预览=快照原文；
6. 使用统计：同指纹二连击 hit_count=2；
7. 查询日志：问数链路写入字段完整（与 M16 联测）；金标种子过滤 success（与 M20 联测）。
