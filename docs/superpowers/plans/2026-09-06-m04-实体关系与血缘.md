# M04 实体关系与血缘 实现计划（金标准）

> **面向 AI 代理的工作者：** 必需子技能：使用 subagent-driven-development（推荐）或 executing-plans 逐任务实现此计划。步骤使用复选框（`- [x]`）语法来跟踪进度。

**目标：** 从零构建实体数据运营层——三组实体关系管理（层级硬校验+打点归一+Excel 双向）、主数据/活动数据共享树管理器（属性维护+三种数据来源模式+数据预览）、实体关系管理页、跨页联动 store、血缘占位页。

**架构：** 关系管理走独立 API（entity_relation_manage.py，/entity-relation-manager/*）；三组关系由概念层级（L2/L4）硬校验；master_activity 组全链路（create/update/import）强制 relation_category=打点维护；前端共享 ModelTreeManager 薄壳复用；跨页状态走全局 store（高亮/定位/映射跳转）。

**技术栈：** FastAPI、SQLAlchemy、pandas（Excel）、React+AntD+Zustand（store）。

**规格来源：** `docs/superpowers/specs/2026-09-06-m04-实体关系与血缘-design.md`。

**纪律：** 打点语义单一来源（API 层归一）；薄壳复用禁止复制分叉；字段保存就地更新不整树刷新。
