# M15 知识库与工单 实现计划（金标准）

> **面向 AI 代理的工作者：** 必需子技能：使用 subagent-driven-development（推荐）或 executing-plans 逐任务实现此计划。步骤使用复选框（`- [x]`）语法来跟踪进度。

**目标：** 从零构建两个轻域——RAG 知识库（建库/上传/分块向量化/检索/三处级联删除，复用 M09 基础设施）与工单只读 API（n8n 编排面，字段白名单裸 SQL）。

**架构：** 原文在磁盘、向量在 Qdrant（每库一 collection）、元数据在 MySQL；vectorize 编排（分块→embed_texts→upsert）；工单无 ORM 白名单 SELECT。

**技术栈：** FastAPI、Qdrant（经 TupuQdrantClient）、M09 embed_texts、文件 IO。

**规格来源：** `docs/superpowers/specs/2026-09-06-m15-知识库与工单-design.md`。

**纪律：** 基础设施只复用不自建；删库三处同步清；工单保持只读白名单。
