# M13 智能技能与工作流 实现计划（金标准）

> **面向 AI 代理的工作者：** 必需子技能：使用 subagent-driven-development（推荐）或 executing-plans 逐任务实现此计划。步骤使用复选框（`- [x]`）语法来跟踪进度。

**目标：** 从零构建技能工作流域——技能包体系（五件套 ZIP/版本/文件树/SKILL.md 解析）、执行三通道（同步/异步/任务队列）+ Worker 控制、调试会话（断点/单步/变量）、智能技能管道（三场景/挂起续跑/rewind 回溯）、统一 Run（会话/Run/事件 SSE）、配套（模板/调度声明/密钥/类型/快照）。

**架构：** 包-版本-快照三层；三执行通道共享 ExecutionEngineV2；管道状态机（waiting_user_input/rewound/parent_run_id 回溯链）；统一 Run 是唯一新会话入口（chat.py 冻结）。

**技术栈：** FastAPI、SQLAlchemy、zipfile（五件套）、SSE（事件流）、React+AntD。

**规格来源：** `docs/superpowers/specs/2026-09-06-m13-智能技能与工作流-design.md`。

**纪律：** 密钥与技能分离（secrets 脱敏）；新会话功能禁走 chat.py；rewind 不删原 run。
