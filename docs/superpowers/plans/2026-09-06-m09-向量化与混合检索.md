# M09 向量化与混合检索 实现计划（金标准）

> **面向 AI 代理的工作者：** 必需子技能：使用 subagent-driven-development（推荐）或 executing-plans 逐任务实现此计划。步骤使用复选框（`- [x]`）语法来跟踪进度。

**目标：** 从零构建向量执行层——Qdrant 客户端封装基座、三组集合（词条/实体/属性）同步与检索、MySQL 意图 embedding 双后端（嵌入引擎本地+API 双模式、混合评分）、混合检索词法管线（分词/停用词/双源同义词/数字过滤）。

**架构：** 大规模近邻走 Qdrant（经 TupuQdrantClient 唯一封装），小规模意图资产走 MySQL 表 Python 余弦；同步幂等（force 重建/content_hash 增量）；Qdrant 故障全线降级不 500。

**技术栈：** qdrant-client、jieba、sentence-transformers（本地模式）/OpenAI 兼容 API、SQLAlchemy。

**规格来源：** `docs/superpowers/specs/2026-09-06-m09-向量化与混合检索-design.md`。

**纪律：** 裸 Qdrant client 禁止出业务层；新需求先判规模再选后端；数字/停用 token 必须剔除。
