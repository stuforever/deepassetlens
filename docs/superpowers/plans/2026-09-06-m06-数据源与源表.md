# M06 数据源与源表 实现计划（金标准）

> **面向 AI 代理的工作者：** 必需子技能：使用 subagent-driven-development（推荐）或 executing-plans 逐任务实现此计划。步骤使用复选框（`- [x]`）语法来跟踪进度。

**目标：** 从零构建数据资产登记面——数据源配置 CRUD+探活、三类源表全量替换登记、源表关系、字段级元数据 Excel 导入与 CRUD、元数据只读视图层（快照/分域/问数视角/诊断）、同步触发面（图谱/向量运维入口）。

**架构：** DataSourceConfig 独立表（联邦 catalog 前缀列）；三类源表整表替换语义；字段导入 20+ 列外部契约；metadata 视图全部只读（service 构建 bundle/view）；data_sync 触发与执行分离（执行体在 M05/M09）。

**技术栈：** FastAPI、SQLAlchemy、pandas/openpyxl（Excel）、pymysql/psycopg2 等（按 db_type 探活）。

**规格来源：** `docs/superpowers/specs/2026-09-06-m06-数据源与源表-design.md`。

**纪律：** bulk_save=整表替换不搞局部 merge；导入列名不改写；视图无写面；password 现状明文（改动须过设计批次）。
