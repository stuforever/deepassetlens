# M14 调度与后台作业 实现计划（金标准）

> **面向 AI 代理的工作者：** 必需子技能：使用 subagent-driven-development（推荐）或 executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 从零构建后台执行域——TaskQueue 模型、TaskWorker 单线程消费协议（优先级/独立 session/有界重试/周期钩子）、TaskWorkerManager、启动注册（worker+两周期作业）、调度声明存储（投递器按现状登记为未实现，不在本计划虚构）。

**架构：** 单 daemon 线程顺序消费；with_for_update 取队防双消费；expunge 独立 session 执行；周期作业唯一入口 register_periodic。

**技术栈：** threading.Event/Lock、SQLAlchemy with_for_update。

**规格来源：** `docs/superpowers/specs/2026-09-06-m14-调度与后台作业-design.md`。

**纪律：** 禁自建定时线程；重试上限硬编码于协议；投递器实现须另过设计批次。

def test_periodic_hook_interval_and_isolation():
    import time
    from app.core.task_worker import TaskWorker
    w = TaskWorker(poll_interval=0.02)
    calls = []
    w.register_periodic(0.05, lambda: calls.append(1))
    w.register_periodic(0.05, lambda: 1 / 0)          # 异常钩子
    w._run_periodic_hooks(); time.sleep(0.06); w._run_periodic_hooks()
