# M21 引擎执行与结果治理 实现计划（金标准）

> **面向 AI 代理的工作者：** 必需子技能：使用 subagent-driven-development（推荐）或 executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 从零构建执行底座——安全执行器（SELECT-only/白名单/强制 LIMIT）、错误分类体系（error_class 唯一契约）、Doris 池化执行、物理表执行、DuckDB API 联邦（分页/Parquet 缓存/熔断限流）、单值聚合加速器（拦截/刷新/周期挂载）、查询日志（记录/清理/列表）。

**架构：** 先校验后执行双闸门（模板守卫→安全底座）；error_class 跨模块信号；加速器宁慢勿错（条件不满足放行原路径）；日志即观测。

**技术栈：** sqlglot、pymysql（Doris）、duckdb+pandas+pyarrow、SQLAlchemy、requests。

**规格来源：** `docs/superpowers/specs/2026-09-06-m21-引擎执行与结果治理-design.md`。

**纪律：** error_class 新增须过设计（M19 联动评审）；加速器条件不放宽；日志不落为缺陷。
