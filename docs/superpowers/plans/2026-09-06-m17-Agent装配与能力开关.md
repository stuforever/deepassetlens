# M17 Agent 装配与能力开关 实现计划（金标准）

> **面向 AI 代理的工作者：** 必需子技能：使用 subagent-driven-development（推荐）或 executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 从零构建装配层——能力开关中心（白名单打勾制/红线五件/锁定三件/DecisionGate/事件审计）、Agent 装配器（fail-safe 三段/三因子缓存键/LRU/Checkpointer/规则常量族/种子/Rubric/SQL 纠错）、能力开关 API、前端安全控制中心能力面板。

**架构：** 三因子缓存键（conn#g 守卫#c 能力#f 文件哈希）=「PATCH 后下一问生效」唯一语义；红线物理排除、锁定件不可取消；fail-safe 三段兜底；一切装配行为写事件。

**技术栈：** deepagents（create_deep_agent/HarnessProfile/AgentMiddleware）、langgraph checkpoint（AsyncSqliteSaver）、FastAPI。

**规格来源：** `docs/superpowers/specs/2026-09-06-m17-Agent装配与能力开关-design.md`。

**纪律：** 工具放行只有打勾一条路；配置基准钉死代码；未知能力注册须显式入表。
