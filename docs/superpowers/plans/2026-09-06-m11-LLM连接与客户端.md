# M11 LLM 连接与客户端 实现计划（金标准）

> **面向 AI 代理的工作者：** 必需子技能：使用 subagent-driven-development（推荐）或 executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 从零构建 LLM 面——连接配置池（capability 分池/env 密钥占位）、管理 API 九端点（CRUD/复制/测试/试验场/planner）、统一客户端（LangChain ChatOpenAI 构建+裸调用三族+用量与缓存观测内建）。

**架构：** DB 驱动连接池是全平台唯一 LLM 入口；选择函数静默降级（None+warning），降级策略收口在装配层；观测是调用原语的一部分。

**技术栈：** langchain-openai（ChatOpenAI）、requests/httpx（裸调用）、FastAPI、SQLAlchemy。

**规格来源：** `docs/superpowers/specs/2026-09-06-m11-LLM连接与客户端-design.md`。

**纪律：** 禁止硬编码 LLM 连接；密钥优先 `${ENV}` 占位；新调用场景先看能否复用三族裸调用。
