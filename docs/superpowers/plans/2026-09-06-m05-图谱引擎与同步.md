# M05 图谱引擎与同步 实现计划（金标准）

> **面向 AI 代理的工作者：** 必需子技能：使用 subagent-driven-development（推荐）或 executing-plans 逐任务实现此计划。步骤使用复选框（`- [x]`）语法来跟踪进度。

**目标：** 从零构建图谱引擎层——driver 单例与健康降级、MySQL→Neo4j 全量投射（单一 Category+ChainRoot 体系，MERGE 幂等）、实体/关系增量同步、邻居展开、kg_api 9 端点 HTTP 面（连接隐藏）、图可视化三端点、业务链 spec 层级同步、辅助资产三表。

**架构：** MySQL 唯一事实源，Neo4j 是投射视图；code 为幂等键（概念 `L{n}-{id前8}`、实体 entity_code）；kg_api 把查询函数 HTTP 化供 Agent 工具与前端调用；Neo4j 不可用全线静默降级。

**技术栈：** neo4j Python driver、FastAPI、SQLAlchemy。

**规格来源：** `docs/superpowers/specs/2026-09-06-m05-图谱引擎与同步-design.md`。

**纪律：** Neo4j 上不做业务写；连接串不出后端；hop/limit 夹取；老双轨路径行为冻结（收编须过设计批次）。
