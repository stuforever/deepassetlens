# M19 守卫与安全体系 实现计划（金标准）

> **面向 AI 代理的工作者：** 必需子技能：使用 subagent-driven-development（推荐）或 executing-plans 逐任务实现此计划。步骤使用复选框（`- [x]`）语法来跟踪进度。

**目标：** 从零构建执行拦截层——SkillPolicyMiddleware 十项硬校验（两次违规则终止）、SQL 模板严格派生守卫（sqlglot AST/WHERE 合取剪枝）、纠错指引体系（五类/2·3 上限/SECURITY_VALIDATION 禁重试）、定位预算+同参去重（P0 死循环防线）、HITL 人审中断（两类触发/180s 超时/跨请求 Future 注册表）、守卫配置中心+试探单+API+前端面板。

**架构：** 永不回退自由问答；第一次教学式拒绝、第二次终止；人审只许 TABLE/CATALOG_MISSING 两类；守卫 PATCH 版本进 Agent 缓存键。

**技术栈：** langchain AgentMiddleware、sqlglot、asyncio.Future（HITL）。

**规格来源：** `docs/superpowers/specs/2026-09-06-m19-守卫与安全体系-design.md`。

**纪律：** 拦截失败唯一出口=失败卡；纠错指引条文改动须过设计（前缀缓存联动）；定位预算调大须评估死循环风险。

def test_derived_ok():

        "SELECT cust_id, status FROM biz_cust WHERE status = '在用' LIMIT 100", TPL)
    assert ok


def test_add_predicate_rejected():
    ok, why = validate_against_template(
        "SELECT cust_id FROM biz_cust WHERE status='在用' AND fee > 0 LIMIT 10", TPL)
    assert not ok


def test_union_and_write_rejected():
    for bad in ["SELECT 1 UNION SELECT 2", "DELETE FROM t", "SELECT * FROM t WHERE x={v}"]:
        ok, _ = validate_against_template(bad, TPL)
        assert not ok
