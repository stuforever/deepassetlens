# M22 治理观测与运行分析 实现计划（金标准）

> **面向 AI 代理的工作者：** 必需子技能：使用 subagent-driven-development（推荐）或 executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 从零构建观测诊断面——四读端点（健康/缓存/日志/熔断）、Pushdown 调试器（不真实执行的下推树+未下推审计）、Doris EXPLAIN/Profile 代理、加速器管理面、引擎工作台前端。

**架构：** 观测只读；诊断与执行共用同一解析函数（诊断=真实行为）；error_class 契约一致；观测呈现就近不建中台。

**技术栈：** FastAPI、sqlglot（复用 M21 解析）、urllib（FE HTTP 代理）。

**规格来源：** `docs/superpowers/specs/2026-09-06-m22-治理观测与运行分析-design.md`。

**纪律：** pushdown debug 禁真实执行；诊断解析函数与执行器同一实现（禁分叉）。
