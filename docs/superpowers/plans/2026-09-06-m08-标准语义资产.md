# M08 标准语义资产 实现计划（金标准）

> **面向 AI 代理的工作者：** 必需子技能：使用 subagent-driven-development（推荐）或 executing-plans 逐任务实现此计划。步骤使用复选框（`- [x]`）语法来跟踪进度。

**目标：** 从零构建语义词法资产面——标准语义词条全生命周期（图谱抽取→向量化任务→语义查询→导出，content_hash 变更检测+重试态）、同义词组、停用词、标准字典、四族归一化规则（服务层）、nl2cypher 模板/schema 管理面、字段级溯源分析端点。

**架构：** 词条表带 vector_status 状态机与任务进度表；向量化执行体在 M09（本模块编排任务与状态）；归一化规则全表驱动；双同义面（SynonymGroup=检索改写 / StandardDict=口径映射）。

**技术栈：** FastAPI、SQLAlchemy、（执行期）M09 向量服务与 M11 LLM 客户端。

**规格来源：** `docs/superpowers/specs/2026-09-06-m08-标准语义资产-design.md`。

**纪律：** 词条不凭空手造（图谱回链）；content_hash 变更必须重向量化；四族归一管理面未建（启用须过设计）；新端点不塞本文件（§六归属标注）。
