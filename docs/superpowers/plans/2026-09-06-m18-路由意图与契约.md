# M18 路由意图与契约 实现计划（金标准）

> **面向 AI 代理的工作者：** 必需子技能：使用 subagent-driven-development（推荐）或 executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 从零构建决策层——技能目录解析（SKILL.md frontmatter→StepDefinition）、场景路由（RouteResult）、规则意图族（零 LLM）、QueryContract 双构造器（场景/通用+澄清模式+场景禁 read_file）、引擎路由（三模式决策）、输出契约执行体、问属性链（目录/召回/校验/面板）。

**架构：** 决策与执行分离（本模块产裁决数据、M19 执行拦截）；澄清优于乱查；引擎真实映射禁止臆想；指引/规则族为固定文案成分（前缀缓存纪律）。

**技术栈：** 纯 Python（正则/关键词）、dataclass 契约、FastAPI（预览端点在 M16 挂载）。

**规格来源：** `docs/superpowers/specs/2026-09-06-m18-路由意图与契约-design.md`。

**纪律：** 契约字段模型不可改写（仅 _runtime 由代码更新）；ABSOLUTE_FORBIDDEN 只加不减；新意图规则先过设计。
