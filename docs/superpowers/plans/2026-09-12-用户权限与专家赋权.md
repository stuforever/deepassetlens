## 一、纪律

**不动清单**：①-⑤+⑤补+A 件交付物语义；auth 四表/七端点/中间件结构（只接执法不改建）；`_DEFAULT_ROLE_PERMS` 不动（operator 面等真实需求——spec 诚实账⑤）；e2e 存量选择器；dev-login（auth=0 期间是 e2e 生命线）。

**行为契约（D2 判定规则）**：执法点统一调 `check_resource_permission`（core/auth.py L589）；**admin 一票通过**；否则 `user 直授 ∪ role 授权` 命中即过；`use`=可见可用（门户+对话+功能页）、`manage`=+专家后台。**公共语义种子化**：wenshu→role viewer→use（登录兜底 viewer L279-280→全员可用）；tutor 等不种=默认私有——「专家赋权给用户」正场景。

**铁律**：`use`/`manage` 是**新动作名**（actions JSON 自由子集——models/auth.py L78 注释为例示非锁，登记 M00 词汇表）；执法点 4 前端守卫**管体验不管安全**（数据面已被 API 挡——A 件 A-4 联调对齐）；赋权面写路径=grant 三端点既有面（后端零新增）。
