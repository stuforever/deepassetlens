# M01 工程基座与数据模型 实现计划（金标准）

> **面向 AI 代理的工作者：** 必需子技能：使用 subagent-driven-development（推荐）或 executing-plans 逐任务实现此计划。步骤使用复选框（`- [x]`）语法来跟踪进度。

**目标：** 从零构建全后端地基——进程入口（28000 单进程）、DB 核心（池化+轻量兼容迁移）、83 表数据模型（11 域分组）、幂等种子、TaskWorker 后台线程、12 钩子启动生命周期、环境文件族。

**架构：** SQLAlchemy 单 engine + sessionmaker；`Base.metadata.create_all` 建表 + `ensure_schema_compatibility()` 补列（无 Alembic，刻意取舍）；lifespan 按「fail-fast 安全检查 → 建表种子迁移 → 三同步 → worker → 检查预热」编排；TaskWorker 守护线程消费 TaskQueue 并挂周期钩子。

**技术栈：** FastAPI/uvicorn、SQLAlchemy(pymysql/MySQL)、threading（TaskWorker）。

**规格来源：** `docs/superpowers/specs/2026-09-06-m01-工程基座与数据模型-design.md`。

**纪律：** 端口 28000 不可改；workers=1 不可改；重启必设 `PYTHONUTF8=1`；每任务独立 commit。

```python
import logging
import os

from sqlalchemy import create_engine, inspect, text
from sqlalchemy.orm import sessionmaker

logger = logging.getLogger(__name__)

DATABASE_URL = os.getenv("DATABASE_URL", "mysql+pymysql://root:root@localhost:33066/tupu?charset=utf8mb4")

engine = create_engine(
    DATABASE_URL,
    pool_pre_ping=True,      # 取连接前 ping，断连自愈
    pool_recycle=3600,       # MySQL wait_timeout 内主动回收
    pool_size=10,
    max_overflow=20,
)
SessionLocal = sessionmaker(autocommit=False, autoflush=False, bind=engine)


def ensure_schema_compatibility():
    """轻量列级兼容迁移：旧库补新列，避免接口 500（模式见 spec §二.4）。"""
    inspector = inspect(engine)
    table_names = set(inspector.get_table_names())
    _patch_columns(inspector, table_names, "kg_entities", {
        "entity_en_name": "VARCHAR(255)", "entity_explanation": "TEXT",
        "sort_order": "INT NOT NULL DEFAULT 0",
        "source_mode": "VARCHAR(30) NOT NULL DEFAULT 'physical_table'",
        "integration_sql": "TEXT NULL", "doris_catalog": "VARCHAR(255)",
        "data_source_id": "VARCHAR(36) NULL",
    })
    # ……每域表的新增列同款补齐（kg_source_field_imports/kg_llm_connection_configs/
    # kg_data_source_configs 等，实施时按 spec §九锚点逐表登记）；值迁移一次：
    #   UPDATE kg_entities SET source_mode='physical_table' WHERE source_mode='table' 等


def _patch_columns(inspector, table_names, table, cols: dict):
    if table not in table_names:
        return
    existing = {c["name"] for c in inspector.get_columns(table)}
    alters = [f"ALTER TABLE `{table}` ADD COLUMN `{c}` {t}"
              for c, t in cols.items() if c not in existing]
    if alters:
        with engine.begin() as conn:
            for sql in alters:
                conn.execute(text(sql))
```

def test_task_worker_priority_and_retry(tmp_session_with_tasks):
    """高优先级先执行；失败未达 max_retries 回 pending 并计数。"""
    worker = TaskWorker(poll_interval=0.05)
    # 造两条 pending（priority 2 / 1），断言消费顺序 [1, 2]；
    # 造必失败任务 max_retries=1，第一轮失败后 status=='pending' 且 retry_count==1，
    # 第二轮失败后 status=='failed'。


def test_periodic_hook_interval():
    worker = TaskWorker(poll_interval=0.02)
    calls = []
    worker.register_periodic(0.05, lambda: calls.append(1))
    worker._run_periodic_hooks(); time.sleep(0.06); worker._run_periodic_hooks()
    assert len(calls) == 2        # 间隔前不触发、间隔后触发
