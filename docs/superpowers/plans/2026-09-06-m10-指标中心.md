# M10 指标中心 实现计划（金标准）

> **面向 AI 代理的工作者：** 必需子技能：使用 subagent-driven-development（推荐）或 executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 从零构建指标全生命周期——12 表模型、21 端点（CRUD+7 子资源整组替换+版本快照+审批状态机+审计+血缘+回滚）、前端四 Tab 详情与工作流。

**架构：** 双口径轨主档；发布即快照（rollback=恢复快照）；子资源 PUT 整组替换；过滤白名单（字段+算子）为问数安全边界；使用统计按查询指纹聚合。

**技术栈：** FastAPI、SQLAlchemy、React+AntD。

**规格来源：** `docs/superpowers/specs/2026-09-06-m10-指标中心-design.md`。

**纪律：** 白名单变更须走审批流；deps 计算侧容忍环；operator 必填（RBAC 挂接为登记项）。
