# M03 概念体系与四区建模 实现计划（金标准）

> **面向 AI 代理的工作者：** 必需子技能：使用 subagent-driven-development（推荐）或 executing-plans 逐任务实现此计划。步骤使用复选框（`- [x]`）语法来跟踪进度。

**目标：** 从零构建概念层——L0-L4+L2X/L4X 双链概念体系、概念/实体/实体关系 CRUD（含英文名治理三件套）、Excel 导入导出、资产矩阵（L2×L4 打点）、前端四视图建模画布（力导向/四区/矩阵/图库）。

**架构：** FastAPI 聚合路由模式（concept.py 聚合 concept_entity/concept_admin 两个实现子路由 + concept_graph 归 M05）；5 张 MySQL 表（concepts/entities/entity_relations/entity_concept_links/concept_relations）；矩阵=EntityRelation 表上 `relation_category="打点维护"` 的 L2→L4 行；前端 GraphManager 四模式共用数据端点。

**技术栈：** FastAPI、SQLAlchemy、pandas/openpyxl（Excel）、React+AntD+SVG（画布）。

**规格来源：** `docs/superpowers/specs/2026-09-06-m03-概念体系与四区建模-design.md`。

**纪律：** Excel 中文列头=外部契约不可改；level=0 业务域不进图谱；LLM 只做建议不做落库决定。
