# M02 认证与权限 实现计划（金标准）

> **面向 AI 代理的工作者：** 必需子技能：使用 subagent-driven-development（推荐）或 executing-plans 逐任务实现此计划。步骤使用复选框（`- [x]`）语法来跟踪进度。

**目标：** 从零构建统一鉴权面——Authentik OIDC 验签（RS256/JWKS 缓存）、ENABLE_AUTH 双模式、RBAC 三角色 + 资源级 ACL、6 端点认证 API、纯 ASGI 中间件（SSE 不断流）、前端 OIDC 客户端与 Bearer 注入。

**架构：** 纯 ASGI AuthMiddleware 全局拦截（公开/可选/MCP 内部三档路径白名单）→ JWT 验签（JWKS 600s 缓存+旧缓存回退）→ 用户 upsert 镜像 → request.state.user；权限判定五级链（admin→user ACL→role ACL→role 通配→角色默认模板）以 `require_permission`/`check_resource_permission` 两个出口供各域 API 声明。

**技术栈：** PyJWT（RS256）、requests（JWKS/userinfo）、FastAPI Depends、SQLAlchemy（4 表）、前端 fetch+axios 拦截器。

**规格来源：** `docs/superpowers/specs/2026-09-06-m02-认证与权限-design.md`。

**纪律：** dev-login 仅 ENABLE_AUTH=0；生产三件套启动 fail-fast；禁用 BaseHTTPMiddleware（断 SSE）。

def test_jwks_cache_ttl_and_fallback(monkeypatch):
    """JWKS 600s 缓存命中不重复拉；拉取失败回退旧缓存。"""
    from app.core import auth as A
    calls = []
    def fake_get(url, timeout=5):
        calls.append(url)
        class R:
            def raise_for_status(self): pass
            def json(self): return {"keys": [{"kid": "k1"}]}
        return R()
    monkeypatch.setattr(A.requests, "get", fake_get)
    A._JWKS_CACHE.update({"keys": [], "fetched_at": 0.0, "ttl": 600})
    assert A._fetch_jwks() == [{"kid": "k1"}] and len(calls) == 1
    assert A._fetch_jwks() == [{"kid": "k1"}] and len(calls) == 1   # 缓存期内不再拉
    monkeypatch.setattr(A.requests, "get", lambda url, timeout=5: (_ for _ in ()).throw(RuntimeError("down")))
    assert A._fetch_jwks() == [{"kid": "k1"}]                        # 回退旧缓存
