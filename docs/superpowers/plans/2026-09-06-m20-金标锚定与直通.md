# M20 金标锚定与直通 实现计划（金标准）

> **面向 AI 代理的工作者：** 必需子技能：使用 subagent-driven-development（推荐）或 executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 从零构建金标层——kg_golden_qa_set 主表+Qdrant tupu_golden_qa 集合双存、两级检索（Tier1 规范化保底+Tier2 语义增强+降级）、bundle 单调用化（一次 embedding 双集合+60s 短窗缓存）、锚定/实体提示注入块、三级阈值直通数据供给、种子提炼与候选审核、CRUD 七端点、金标管理页。

**架构：** 确定性优先语义增强；双存以 DB 为准；直通豁免动态条件/否定；注入静默降级。

**技术栈：** Qdrant（M09 基座复用）、SQLAlchemy、OrderedDict 短窗缓存。

**规格来源：** `docs/superpowers/specs/2026-09-06-m20-金标锚定与直通-design.md`。

**纪律：** 金标只供构造参考；直通三级阈值不合并；管理操作后清 bundle 缓存。
