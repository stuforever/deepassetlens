## 三、缺陷清单（按优先级）

### P1 违反铁律（应尽快修）
1. **`ContractCardsPanel.tsx` 硬编码色值**：DOT 常量直写 hex（:44-50）；两处 **`#1677ff` 是 antd 默认蓝，非本品牌色 #2563EB**（:202、:238）--违反「token 唯一来源」铁律，且颜色本身是错的。

### P2 规格明确要求但未实现（8 项）
2. `:focus-visible` 全局焦点环（规格 0.6，无障碍底线）
3. chartPalette 上图（C34；现为死 token）
4. ResultTable 列类型图标 + 数字列右对齐/tabular-nums（C19）
5. StatusTag「进行中」脉冲（C43）
6. EmptyState illustration 位（C45）
7. ErrorState 技术详情折叠（C46）
8. DrawerFooter 推广到各管理页抽屉（C44）
9. 胶囊条「运行中当前步骤」脉冲（C17）

### P3 小偏差（可接受，不强制改）
- 菜单 margin-inline 4≠8；页签高 30≠28；Send 圆形≠方形；Stop 实心≠白底红边；composer maxWidth 800≠720；主标题挂 dal-mono；`dal-reading` 定义零使用（死 CSS）；密度开关不持久化；点阵色值变体、覆盖画布不全；图例不可折叠；minimap 高 140≠120；Header z100 未设；gradientHover 用 opacity 替代；搜索框默认/hover 底色未做。

## 五、结论

- **B1/B2（框架+旗舰页）质量高**，核心视觉目标（玻璃顶栏、Chrome 页签、渐变主视觉、胶囊条、S1/S3 阴影体系、骨架屏、reduced-motion）全部达成，多处超出规格（可达性、全屏、事件徽标）。
