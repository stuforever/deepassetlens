# DeepAssetLens 前端界面美化重设计

- 日期：2026-08-17 ｜ 性质：**纯设计文档，不含代码修改**
- 前置设计：《受控 Skill 问答平台提升设计》（五张业务卡 / RouteSimulator 已定稿）
- 适用范围：`frontend/` 全部页面（对话旗舰页 + 画布页 + 管理页 + 全局框架）

---

## 1. 设计目标

把当前「能用但素」的界面，升级为「专业数据工作台」质感，同时严格遵守三条已有原则：

1. **业务可读优先**：领导默认看到结论与业务卡，技术细节折叠（延续受控 Skill 平台设计）。
2. **Token 唯一来源**：延续 `theme/tokens.ts` 铁律，本设计只**扩展 token**，不允许新增硬编码颜色/间距/圆角。
3. **零新依赖**：只用 CSS + antd token + `@ant-design/icons`，不引入 framer-motion、新图标库、新字体包。

### 现状盘点（实测，非推测）

**已经是好底子（保留并复用）：**

- `tokens.ts` 双通道消费体系成熟：antd `ConfigProvider cssVar`（key: `tupu`）+ `index.css` 同名 CSS 变量 + TS 常量直引。
- Shell 组件族已存在：`shell/PageShell / PageHeader / DataTableShell / FilterBar / StatusTag / EmptyState / ErrorState / CanvasToolbar`。
- 对话页已落地受控 Skill 第三批的核心件：`contractCards/ContractCardsPanel + RouteCard/ScopeCard/DataAccessCard/ExecutionDecisionCard/StopReasonCard + RouteSimulator`。
- `AssistantCanvas` 连续流版式（豆包/ZCode 风格）方向正确：标题左竖线、摘要、发现胶囊、推荐问题虚线分隔、SQL 折叠。

**需要美化解决的（本设计主战场）：**

| 问题 | 现状证据 | 影响 |
|---|---|---|
| 界面「平」 | 全站无阴影层级（tokens 无 elevation），白底+细边线到底 | 缺乏层次与专业感 |
| 无动效体系 | 全站仅零星 `transition: color .15s`，无统一时长/曲线 | 交互反馈生硬 |
| 落地页单薄 | 居中文字 + 4 条纯文本示例 + 统计为纯数字 | 旗舰页第一观感弱 |
| 会话列表拥挤 | 编辑/删除图标 10px 常驻（`AppSider.tsx:228-242`） | 视觉噪音 |
| 卡片信息平铺 | 契约五卡默认「折叠状态条」，但展开后仍是表单式罗列 | 业务阅读效率低 |
| 结果表朴素 | 标准 antd Table，无列类型标识、无工具条 | 数据可读性一般 |
| 画布页缺氛围 | 画布白底、无图例/小地图规范 | 图谱页像半成品 |
| 加载/空/错态 | 仅 EmptyState/ErrorState 基础件，无骨架屏、无插画 | 等待与异常体验粗糙 |

## 2. 视觉语言升级（token 层扩展）

只做**增量扩展**，不动既有 token 值，零迁移成本。

### 2.1 阴影层级（新增 `elevation` token）

| 级别 | 用途 | 规格（写进 tokens.ts / index.css） |
|---|---|---|
| `S0` | 默认平铺 | 无 |
| `S1` | 卡片静置、结果表容器 | `0 1px 2px rgba(15,23,42,.04), 0 1px 3px rgba(15,23,42,.06)` |
| `S2` | 悬浮、Popover、悬停卡片 | `0 4px 12px rgba(15,23,42,.08), 0 2px 4px rgba(15,23,42,.04)` |
| `S3` | Modal、Drawer、输入 composer | `0 12px 32px rgba(15,23,42,.14), 0 4px 8px rgba(15,23,42,.06)` |

规则：**卡片用「S1 + 1px border」组合，不再裸边框；悬浮抬升到 S2。**

### 2.2 品牌渐变（新增，克制使用）

- `brand-gradient: linear-gradient(135deg, #2563EB 0%, #7C3AED 100%)`
- 只允许出现在 3 处：**落地页主视觉文字**、**AI 能力徽标**、**主发送按钮**。禁止大面积铺。

### 2.3 图表色板（新增 `chart` 序列，给画布/图谱用）

8 色分类板（基于现有蓝/紫扩展，保证与品牌协调）：

```text
#2563EB  #7C3AED  #0891B2  #059669  #D97706  #DC2626  #64748B  #BE185D
```

图谱节点/矩阵区块/血缘边一律从此取色，循环使用，禁止随机色。

### 2.4 字排升级（扩 `fontSize`）

| token | 值 | 用途 |
|---|---|---|
| `display` | 28 | 落地页主视觉（仅此一处） |
| `pageTitle` | 20 | 不动 |
| `sectionTitle` | 16 | 不动 |

新增排版规则（写入全局 CSS）：

- 数据/表格/编号列：`font-variant-numeric: tabular-nums`（数字等宽对齐，对比行数据不跳动）；
- 阅读区（答案正文/摘要）：`line-height: 1.75`，中文段落 `letter-spacing: 0.01em`；
- 代码/SQL：统一等宽栈 `ui-monospace, Consolas, 'JetBrains Mono', monospace`（系统栈，不下载字体）；
- 落地页主视觉用 `font-weight: 700; letter-spacing: -0.02em`，配合 2.2 渐变文字。

### 2.5 动效 token（新增 `motion`）

| token | 值 | 用途 |
|---|---|---|
| `duration.fast` | 120ms | hover/按钮反馈 |
| `duration.base` | 200ms | 页签切换、卡片展开 |
| `duration.slow` | 320ms | Drawer/Modal、画布元素入场 |
| `easing.enter` | `cubic-bezier(.2,.8,.2,1)` | 进入 |
| `easing.exit` | `cubic-bezier(.4,0,.6,1)` | 退出 |

**性能红线（与流式输出共存）：** 动画只动 `transform/opacity`；**流式文本节点禁止挂阴影/filter**（重绘开销），阴影只加在静态容器上；`prefers-reduced-motion` 时全局禁用。

## 3. 全局框架重设计

### 3.1 顶栏（48px 不变）

- **玻璃拟态**：`background: rgba(255,255,255,.8) + backdrop-filter: blur(8px)`，底边线保留。
- 左侧品牌区：新增 24×24 **渐变 logo 块**（brand-gradient，圆角 6）+ 文字「DeepAssetLens」，副标题「资产深度探查平台」降为 12px  tertiary。
- 全局搜索：宽 220→260，圆角改 pill（999），聚焦时 S2 阴影。
- 右侧：用户徽标左侧新增**环境徽标**（dev=warning 色点、prod=success 色点），一眼区分环境。

### 3.2 左侧导航（216px 不变）

- 菜单项：hover 时 `bg-hover` 圆角 6 浮起（现为直角选中底色），选中项保留 `primaryBg + 主色文字`。
- **会话列表净化**：编辑/删除图标**默认隐藏，hover 该行才浮现**（现为 10px 常驻）；激活项保留左竖线。
- 分组标题行加 4px 上间距节奏；手风琴展开用 `duration.base + easing.enter`。
- 收起态（64px）：会话区隐藏不变，菜单图标居中，tooltip 补名称。

### 3.3 页签条（36px 不变）

- 从「选中填底色」改为 **Chrome 式页签**：活动页签 = 白底 + S1 阴影 + 顶部 2px 主色条；非活动 = 透明底 + tertiary 文字，hover 出 `bg-hover`。
- 关闭按钮默认 60% 透明，hover 行才实色；右键菜单不变。

### 3.4 内容区

- 管理类页面：`PageShell` 卡片容器统一 S1 + radius.card。
- 画布类页面：背景从纯白改为**点阵网格**（radial-gradient 1px 点 / 24px 间距 / border 色 40% 透明），图谱立刻有「画布感」。

## 4. 旗舰对话页重设计（首页 FreePlanChat）

### 4.1 落地页（空会话）

```text
┌──────────────────────────────────────────┐
│        [渐变文字] 数据资产探查            │
│   一句话问数 · 受控执行 · 全程可审计       │
│                                          │
│   ┌──────┐ ┌──────┐ ┌──────┐            │
│   │主数据 │ │业务实体│ │ 关系 │  ← 3 枚统计│
│   │ 128  │ │  56  │ │ 312  │    胶囊卡   │
│   └──────┘ └──────┘ └──────┘            │
│                                          │
│   ┌──────── 悬浮输入 composer ────────┐  │
│   │  想问什么数据？            [发送▸] │  │
│   └────────────────────────────────────┘  │
│                                          │
│   ┌─────────┐ ┌─────────┐               │
│   │ 示例问题1│ │ 示例问题2│  ← 2×2 建议卡 │
│   ├─────────┤ ├─────────┤    （带图标） │
│   │ 示例问题3│ │ 示例问题4│               │
│   └─────────┘ └─────────┘               │
└──────────────────────────────────────────┘
```

- 主视觉：`fontSize.display` + brand-gradient 文字。
- 统计胶囊：图标 + tabular-nums 数字 + 12px 说明，S1 卡。
- 示例问题从「纯文本列表」改为 **2×2 建议卡**：图标 + 问题 + hover 抬升 S2。
- **悬浮 composer**：radius 12、S3 阴影、聚焦时主色 1.5px 描边环；模型选择器收进 composer 左下（当前是页内 Select）；发送按钮用渐变填充，流式中切换为停止键（同位切换，不位移）。

### 4.2 消息流（有会话）

- 用户问题：保持连续流，但加 **12px tertiary 时间戳 + 问题左主色竖线**，与回答区分。
- 回答区沿用连续流；流式时追加 **呼吸光标**（▍ 闪烁，opacity 动画）。
- 滚动到底按钮：新内容到达且用户不在底部时，右下角浮 S2 圆钮。

### 4.3 契约五卡（已有组件，做信息层级美化）

不改数据结构，只改呈现：

- **折叠态 → 「过程胶囊条」**：一行 5 枚胶囊（命中剧本 / 范围 / 引擎 / 决策 / 终止），每枚 = 彩色图标 + 4~8 字摘要 + 状态色点（成功绿/降级黄/阻止红）；一行读完一次运行的全貌。点击胶囊展开对应卡详情。
- 展开态卡片：标题行 = 图标 + 中文名 + 右侧状态 Tag；正文用「描述列表」两列排布（label tertiary / value primary），替代表单式堆叠。
- 颜色规约：路由=primary、范围=info、引擎=success、决策=ai 紫、终止/阻止=按状态色。

### 4.4 结果表（SqlResultTable）

- 容器 S1 + radius.card；表头吸顶（sticky）；行 hover `bg-hover`。
- **列类型图标**：列名前小图标（文本=𝐓 / 数字=# / 日期=📅 / id=🔑），帮助业务用户读表。
- 工具条（右上）：行数徽标 `共 N 行`、复制、导出 CSV、全屏开关。
- 分页：紧凑模式，页码区右侧放「每页 N 条」。
- 空结果：EmptyState 插画位 + 「未查到符合条件的数据」+ 建议改写提示。

### 4.5 推荐问题

从「1. 2. 3. 编号列表」改为 **chip 胶囊流**：圆角 pill、主色文字、`primaryBg` 底、hover 抬升；点击填入 composer。

## 5. 画布页重设计（图谱/四区建模/资产矩阵）

- **背景**：点阵网格（见 3.4）。
- **浮动工具条**：左上悬浮条（S2 阴影 + radius.card + 玻璃拟态），收纳缩放/适应屏幕/布局切换；替代贴边按钮。
- **图例**：左下固定图例卡（节点色 = chart 色板，注明实体类别）。
- **小地图**：右下 minimap（G6 自带 Minimap 插件能力内实现，不引新包），S1 卡。
- **节点**：填充色取 chart 色板，选中态 = 2px 主色描边 + 外发光 4px；hover 显示名称 tooltip。
- **血缘/关系边**：默认 `border-strong` 色，hover 高亮主色；方向箭头统一。

## 6. 管理页规范化（来源表/映射/指标/技能/配置等）

全部走既有 `PageShell` 族，补齐呈现规范：

1. **页面头**：PageHeader = 标题(20) + 一行描述(tertiary) + 右侧主操作按钮（primary 高度 36）。
2. **筛选条**：FilterBar 默认一行、超出折叠「更多筛选 ▾」；查询/重置按钮右对齐。
3. **表格**：DataTableShell 统一 S1 容器；表头 `bg-subtle`；**密度开关**（默认/紧凑，切换 controlHeight 44↔36）放表格工具条右侧。
4. **状态列**：一律 StatusTag（成功绿/警告黄/失败红/进行中蓝+脉冲点）。
5. **抽屉表单**：Drawer 宽度统一 520/720 两档；底部 sticky 操作条（取消 / 确定），内容超长内部滚动。
6. **删除类操作**：Popconfirm 文案统一「删除后不可恢复，确认删除 XX？」。

## 7. 加载 / 空 / 错三态规范

| 场景 | 规范 |
|---|---|
| 表格/卡片加载 | **骨架屏**（antd Skeleton 定制：表=3 行条形，卡=标题+2 行），替代裸 Spin |
| 页面级加载 | 居中 Spin + 8 字内说明文字 |
| 空数据 | EmptyState + 一句话原因 + 主操作（如「去新建」） |
| 错误 | ErrorState + 可读的下一步 + 重试按钮 + 折叠的技术详情（错误码/请求 ID） |
| 流式生成中 | 呼吸光标 + 过程胶囊条实时点亮，不用转圈 |

## 8. 响应式与无障碍底线

- 工作台定位桌面端：断点 ≥1280 全布局；1024~1280 侧栏自动收起 64px；<1024 提示「请使用桌面浏览器」（不做移动端适配，YAGNI）。
- 对比度：正文/次级文字在各自底色上 ≥4.5:1；主色按钮白字 ≥4.5:1（现 #2563EB 满足）。
- 焦点可见：全站 `:focus-visible` 2px 主色外环（antd 默认偏淡，全局补一道）。
- `prefers-reduced-motion`：禁用非必要动画。

## 10. 不改清单（与美化无关，避免范围蔓延）

- 不动路由/KeepAlive/状态管理结构；
- 不动任何业务逻辑与接口；
- 不动 tokens 既有色值（只新增）；
- 不动 Docker/端口/后端；
- 暗色模式不做（v2 候选，tokens 架构已具备 `darkAlgorithm` 切换条件）。

## 11. 验收总标准

1. 任意页面截图，能用 tokens 名指出每一处颜色/间距/阴影的来源；
2. 旗舰页首屏有「品牌感」，问答全程业务用户不需要展开技术区就能读懂；
3. 画布页有画布感（网格/图例/小地图）；
4. 管理页风格统一，三态（加载/空/错）无裸组件；
5. 动效全部走 motion token，流式路径零阴影/filter；
6. 零新依赖、零硬编码色值、零业务逻辑变更。
