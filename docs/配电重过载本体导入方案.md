# 配电重过载本体导入映射方案（v2 已修正）

> 目标：将 `benti/deploy2` 下两个 SQL 脚本（本体定义 + 样本数据）导入 DeepAssetLens 工程。
> v2 修正点：配电变压器由柱上+非柱上合并；遥测4表直映非视图拆分；互感器规范表名 dwd_cst_it_run；表名去 sim_ 前缀用规范名；字段命名 snake_case↔连写映射；关系 resrc_id→psrid；用电户→计量表计改2跳。

---

## 0. 关键架构事实（执行前必读）

- **kg_* 元数据表建在 MySQL（33066 root/root，库 tupu）**，由 ORM 自动建表，非 PG。
- **sim_* 业务数据表建在 PostgreSQL（5432 postgres/postgres，库 tupu）**，physical_table 实体直查这里。
- **kg_entities.properties_schema** 是 JSON 数组，元素 key = `name/type/cnName/description/isPrimaryKey`（非 en/cn）。
- **kg_entity_relations.join_expr** 格式 = `t0.<源字段> = t1.<目标字段>`，t0=源表，t1=目标表。
- **kg_entity_mapping_rules** 用 `entity_ids`/`source_table_ids`（JSON 数组，复数）。
- 实体插入后**必须插 kg_entity_concept_links 桥表**（entity_id↔concept_id），否则部分链路断。
- 同步：`POST /api/v1/sync/neo4j-all?force=true`（后端 28000，读 33066 MySQL）。

## 二、概念层级设计（kg_concepts，新增 8 个）

```
L0 配电域(新)        [level=0, parent=NULL, area_index=3]

│  ├─ L2 客户(新)    [level=2]
│  ├─ L2 设备(新)    [level=2]

```

> level 惯例：0=域, 1=主数据根, 2=主数据小类, 3=业务活动, 4=业务实体。主数据实体挂 L2(is_main_table=1)，遥测实体挂 L4(is_main_table=0)。

### 4.3 配电变压器 UNION 视图（柱上+非柱上合并）

```sql
CREATE VIEW vw_transformer AS
  SELECT psrid, astid, equipname, feeder, capacity, voltagelevel, pubprivflag, runstate,
         '柱上变压器'::varchar AS transformer_type FROM dwd_grid_psr_ds_p_transformer
  UNION ALL

         '非柱上配电变压器'::varchar AS transformer_type FROM dwd_grid_psr_ds_transformer;
```

## 八、注意点
