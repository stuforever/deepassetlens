### P3 限速/熔断 + Pushdown v2 + parquet 落盘缓存（duckdb_engine）
- **熔断/限速**：`_CIRCUIT_STATE[endpoint_id]={state,failures,opened_at,last_call}`；默认阈值 5、OPEN 时长 60s（端点 `run_config` 可覆盖：`circuit_threshold/circuit_open_seconds/rate_limit_min_interval_ms`）；`_check_circuit` OPEN 快速失败（EngineError UPSTREAM_API「熔断」）、超时转 HALF_OPEN 试探、`_record_success` 复位 CLOSED；`_enforce_rate_limit` 按间隔 sleep；检查点在缓存未命中后、触达上游前；缓存命中跳过。
- **Pushdown v2**：`where_filters[tbl][col]` 值四型——标量=EQ、list=IN、`{"_range":[(op,val)...]}`（GTE/LTE/GT/LT）、`{"_like":"A%"}`（仅纯前缀）；`_build_query_params` 对声明 `range:true/prefix:true`（或 map_to）的参数映射 `{name}_min/_max`、去尾 `%`，未声明不下推；结果附 `pushdown_trace`（逐列 kind eq/in/range/like + pushed_to_api + 值）+ `not_pushed` 审计。
- **parquet 落盘缓存**：DuckDB `COPY (SELECT * FROM _cache_df) TO '...' (FORMAT PARQUET)` + `read_parquet`；`_DISK_CACHE_DIR=backend/data/duckdb_cache`；内存 LRU 命中优先、miss 回退盘文件（TTL 按 mtime）；invalidate 双删；cache_stats 加 `disk_entries`。
- 验证：`tests/test_engine_p3.py` 10 用例全绿；live pushdown/debug 对示例 SQL 输出 `kind=in/range/like` + not_pushed（④）；`/api/engine/circuits` 状态表。
