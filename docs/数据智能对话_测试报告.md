## 五、本次修复的关键问题

本次测试前修复了以下问题，测试验证全部通过：

### 1. boss_router 503 错误（已修复）

**问题**：boss_router 只读环境变量 `MINIMAX_API_KEY`，没读数据库里配的 minimax-m3 连接

**修复**：优先从数据库 `LLMConnectionConfig` 读连接（[main.py](file:///d:/gitcangku/DB-GPT/tupu/backend/data/skills/boss_router/scripts/main.py)）

**验证**：T6 路由准确性 5/5 全过，无 503

### 2. LLM 深度思考太慢（已修复）

**问题**：MINIMAX-M3 默认深度思考（`<think>` 标签），路由简单任务浪费 15 秒

**修复**：读 `extra_config.mode_profiles.quick`，传 `thinking.type=disabled`

**验证**：T6 路由耗时 3-18 秒（之前 30+ 秒）

### 3. 分类查询被误路由到实体定位（已修复）

**问题**：`enforce_state_machine` 把"分类查询"也列入"需先锁 entity"，强制改成实体定位

**修复**：把"分类查询"从 `needs_entity` 移除

**验证**：T6 用例 2/3/4/5 全部正确路由到分类查询

### 4. classification_query interrupt 报错（已修复）

**问题**：`classification_query` 任务用 `langgraph.types.interrupt()`，在 LangGraph 上下文外调用报错

**修复**：去掉 interrupt，改为返回兜底结果

**验证**：T2/T3/T4 分类查询全部无崩溃

### 5. L2-L3 跨链关系缺失（已修复）

**问题**：概念图谱只有 L1-L2、L3-L4 层级关系，缺 L2-L3 跨链抽象关系

**修复**：
- 新建 `ConceptRelation` 表
- 从 L2X-L4X "打点维护"推导 L2-L3 抽象关系
- `/graph/data` 接口返回概念间边

**验证**：力导图现在能看到 L2→L3 紫色虚线跨链连线
