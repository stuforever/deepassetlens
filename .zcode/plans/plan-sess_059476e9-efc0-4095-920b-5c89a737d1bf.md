# 配变数据模型修正 + 剧本台区级计算重构方案

## 一、问题诊断（已排查确认）

| # | 维度 | 当前状态 | 要求 | 修正 |
|---|---|---|---|---|
| 1 | 馈线-配变 | F001->10台 一对多 | 一对多 | ✅ 无需改 |
| 2 | 台区-配变 | 全部1:1 | 多路供电(1台区多配变) | ❌ 重构数据+剧本 |
| 3 | 配变-调压-资产 | 一一对应 | 一一对应 | ✅ 无需改 |
| 4 | 计量点-用户 | 全部1:1 | 一用户可多计量点 | ❌ 重构数据 |
| - | 台区表 | cms20_dist_sta **空表0行** | 需有台区主数据 | ❌ 需填充 |
| - | 计量点-表 | equip_src_id=inst_id 1:1 | 可多表 | 模拟副表测去重 |

**核心根因**：当前第2步 `JOIN 计量点.dist_sta_id = 调压设备.dist_sta_id` 在多路供电台区会产生**笛卡尔积**（1计量点×2配变=2行），导致功率翻倍——这正是用户说的"简单粗暴"。

## 三、SKILL.md 重构（口径改台区级计算）

### 口径定义修改

```
负载率 = 台区汇集功率 / 台区总容量(SUM of 配变容量) × 100%
  - 单路台区: 1配变, 台区总容量=该配变容量
  - 多路台区: 多配变, 台区总容量=所有配变容量之和
连续性: PARTITION BY 负荷类型, 台区编号, date
```

### 第2步重构（核心：拆分功率/容量两条路径，JOIN在台区级）

```sql
WITH 计量点台区 AS (
  -- 计量点->台区(不JOIN配变,避免多路翻倍)
  SELECT DISTINCT
    CASE WHEN inst_usage_cls='01' THEN '用电负载' ... END AS 负荷类型,
    i.inst_id, i.inst_usage_cls, i.dist_sta_id AS 台区编号
  FROM cms20_inst_elec_cons i WHERE i.inst_usage_cls IN ('01','1102','1101')
),
台区容量 AS (
  -- 配变->台区, SUM容量(多路台区容量汇总)
  SELECT v.dist_sta_id AS 台区编号,
    SUM(t.capacity) AS 台区总容量,
    STRING_AGG(t.psrid,',') AS 配变列表,
    STRING_AGG(t.equipname,',') AS 配变名称列表
  FROM cms20_adj_volt_dev v
  JOIN cms20_adj_volt_dev_asset va ON v.adj_volt_dev_asset_id=va.adj_volt_dev_asset_id
  JOIN vw_transformer t ON va.pms_equip_id=t.psrid
  WHERE t.runstate='20'
  GROUP BY v.dist_sta_id
),
dist_power AS (
  -- 台区级功率汇总/台区总容量=负载率
  SELECT m.负荷类型, c.台区编号, c.台区总容量, c.配变列表,
    pw.date, pw.occur_time,
    SUM(CASE WHEN m.inst_usage_cls='1102' THEN abs(pw.power) ELSE pw.power END) AS 负载_kw,
    SUM(CASE WHEN m.inst_usage_cls='1102' THEN abs(pw.power) ELSE pw.power END) / c.台区总容量 * 100 AS 负载率
  FROM 计量点台区 m
  JOIN vw_cust_power_ts pw ON m.inst_id=pw.inst_id
  JOIN 台区容量 c ON m.台区编号=c.台区编号
  WHERE pw.measuerment_type='TotW' -- 【动态】AND pw.date='20260801'
  GROUP BY m.负荷类型, c.台区编号, c.台区总容量, c.配变列表, pw.date, pw.occur_time
),
flagged AS (
  -- 连续8点(PARTITION BY 负荷类型,台区编号,date)
  SELECT ... SUM(...) OVER (PARTITION BY 负荷类型, 台区编号, date ORDER BY occur_time ROWS 7 PRECEDING) ...
)
SELECT 负荷类型, 台区编号, 配变列表, 台区总容量, ... 判定
FROM flagged GROUP BY 负荷类型, 台区编号, 配变列表, 台区总容量
```

### 第3步重构（多计量点客户先SUM后AVG）

```sql
-- 前置CTE同第2步(台区级verdict/over_pts)
-- 关键改动: 客户多计量点先SUM再AVG
cust_agg AS (
  SELECT r.客户类型, r.负荷类型, r.客户编号, r.cust_name,
    r.台区编号, r.台区总容量, pw.date, pw.occur_time,
    SUM(CASE WHEN r.inst_usage_cls='1102' THEN abs(pw.power) ELSE pw.power END) AS 客户负载_kw
    -- ↑ 同客户多计量点在此SUM汇聚(不翻倍,因为是该客户的真实总负载)
  FROM 户变关系 r JOIN vw_cust_power_ts pw ON r.inst_id=pw.inst_id
  JOIN over_pts o ON o.台区编号=r.台区编号 AND o.负荷类型=r.负荷类型 AND o.occur_time=pw.occur_time AND o.date=pw.date
  WHERE pw.measuerment_type='TotW'
  GROUP BY r.客户类型, r.负荷类型, r.客户编号, r.cust_name, r.台区编号, r.台区总容量, pw.date, pw.occur_time
)
SELECT ..., COUNT(*) AS 达标点数,
  ROUND(AVG(客户负载_kw)::numeric,1) AS 平均负载_kW,          -- ←跨时间点AVG
  ROUND(AVG(客户负载_kw)/台区总容量*100::numeric,1) AS 负载占有率
FROM cust_agg GROUP BY ... ORDER BY 负荷类型, 负载占有率 DESC
```

### 第1步调整（展示台区+配变列表）

- 输出增加"台区编号/台区名称"列，配变编号改为"配变列表"(多路时"T031,T032")
- JOIN仍然经过调压设备链路，但多路台区显示多个配变

### 输出规范调整

```
第2步: 负荷类型 | 台区编号 | 台区名称 | 配变列表 | 台区总容量 | 最大负载率 | ... | 判定
第3步: 客户类型 | 负荷类型 | 客户编号 | 客户名称 | 台区编号 | 台区总容量 | 达标点数 | 平均负载 | 负载占有率
一句话结论: "共X个台区, 单路Y个/多路Z个; 过载..."
```
