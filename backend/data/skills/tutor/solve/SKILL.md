# 母题解题（tutor/solve）

## 何时使用
- 用户贴题求解、要求详细解题过程、对解答追问时触发。

## 可用工具
本技能以推理为主；仅在确需外部事实（公式/定理出处、知识点归属）时用
search_kb / web_search。写操作（错题登记、母题固化）走 tutor/practice 技能。

## 执行步骤（vendor question 推理循环语义，平台重写保留）
1. **复述已知与目标**：把题面条件、未知量、约束列清楚（题目格式破损时先修复再解）。
2. **分步推导**：每步给出依据（公式/定理/前一步结论），不跳步。
3. **验证答案**：代入/量纲/特例至少一种手段核验。
4. **最终结论**：明确作答；与题问逐条对应。
5. **追问**：用户对步骤疑惑时，就当前步骤展开，不重复全文。

## 纪律
- 禁止跳过验证环节直接给答案。
- 需要图片题面时走 image_url 通道（模型多模态），不臆造图中内容。
- 解答完毕可建议：把本题固化进母题库（mother_question_find_or_create，两段臂）。
